       NAME

       Copy image between registries with GitHub Actions - Multi-platform images built using Buildx can

       COPY IMAGE BETWEEN REGISTRIES WITH GITHUB ACTIONS

       Multi-platform images built using Buildx can be copied from one registry to another using the buildx imagetools create command:

         name: ci

         on:
           push:

         jobs:
           docker:
             runs-on: ubuntu-latest
             steps:
               - name: Login to Docker Hub
                 uses: docker/login-action@
                 with:
                   username: ${{ vars.DOCKERHUB_USERNAME }}
                   password: ${{ secrets.DOCKERHUB_TOKEN }}

               - name: Login to GitHub Container Registry
                 uses: docker/login-action@
                 with:
                   registry: ghcr.io
                   username: ${{ github.repository_owner }}
                   password: ${{ secrets.GITHUB_TOKEN }}

               - name: Set up QEMU
                 uses: docker/setup-qemu-action@

               - name: Set up Docker Buildx
                 uses: docker/setup-buildx-action@

               - name: Build and push
                 uses: docker/build-push-action@
                 with:
                   platforms: linux/amd64,linux/arm64
                   push: true
                   tags: |
                     user/app:latest
                     user/app:1.0.0

               - name: Push image to GHCR
                 run: |
                   docker buildx imagetools create \
                     --tag ghcr.io/user/app:latest \
                     --tag ghcr.io/user/app:1.0.0 \
                     user/app:latest
