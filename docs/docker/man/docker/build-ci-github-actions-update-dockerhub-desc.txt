       NAME

       Update Docker Hub description with GitHub Actions - You can update the Docker Hub repository description using a third party action

       UPDATE DOCKER HUB DESCRIPTION WITH GITHUB ACTIONS

       You can update the Docker Hub repository description using a third party action called Docker Hub Description with this action:

         name: ci

         on:
           push:

         jobs:
           docker:
             runs-on: ubuntu-latest
             steps:
               - name: Login to Docker Hub
                 uses: docker/login-action@
                 with:
                   username: ${{ vars.DOCKERHUB_USERNAME }}
                   password: ${{ secrets.DOCKERHUB_TOKEN }}

               - name: Set up QEMU
                 uses: docker/setup-qemu-action@

               - name: Set up Docker Buildx
                 uses: docker/setup-buildx-action@

               - name: Build and push
                 uses: docker/build-push-action@
                 with:
                   push: true
                   tags: user/app:latest

               - name: Update repo description
                 uses: peter-evans/dockerhub-description@e98e4d1628a5f3be2be7c231e50981aee98723ae # v4.0.0
                 with:
                   username: ${{ vars.DOCKERHUB_USERNAME }}
                   password: ${{ secrets.DOCKERHUB_TOKEN }}
                   repository: user/app
