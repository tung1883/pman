       NAME

       docker compose alpha watch - Watch build context for service and rebuild/refresh containers when files are updated

       DOCKER COMPOSE ALPHA WATCH

       Watch build context for service and rebuild/refresh containers when files are updated

       USAGE

         docker compose alpha watch [SERVICE...]

       OPTIONS

        * --no-up (bool): Do not build & start services before watching
        * --quiet (bool): hide build output
