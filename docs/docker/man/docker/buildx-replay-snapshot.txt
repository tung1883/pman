       NAME

       docker buildx replay snapshot - Export replay inputs for a subject as a reusable materials store

       DOCKER BUILDX REPLAY SNAPSHOT

       Export replay inputs for a subject as a reusable materials store

       USAGE

         docker buildx replay snapshot [OPTIONS] SUBJECT

       OPTIONS

        * --dry-run (bool): Print a JSON plan of the snapshot without writing output
        * --include-materials (bool): Include material content in the snapshot [default: true]
        * --materials (stringArray): Materials store (repeatable; format: provenance | oci-layout://[:] | | =)
        * --network (string): Network mode for RUN instructions (default | none; defaults to the mode of the original build)
        * --output, -o (stringArray): Output destination (default: - — oci tar to stdout; bare writes an oci-layout directory; type=oci,dest=X[,tar=true|false])
        * --platform (stringArray): Platform of the subject to replay (defaults to the only platform of the subject or the builder default platform)
        * --progress (string): Set type of progress output (auto | plain | tty | quiet | rawjson) [default: auto]
        * --secret (stringArray): Secret to expose to the replayed build (format: id=mysecret[,src=/local/secret])
        * --ssh (stringArray): SSH agent socket or keys to expose (format: default|[=|[,]])
