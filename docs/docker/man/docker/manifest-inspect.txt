       NAME

       docker manifest inspect - Display an image manifest, or manifest list

       DOCKER MANIFEST INSPECT

       Display an image manifest, or manifest list

       USAGE

         docker manifest inspect [OPTIONS] [MANIFEST_LIST] MANIFEST

       OPTIONS

        * --insecure (bool): Allow communication with an insecure registry
        * --verbose, -v (bool): Output additional info including layers and platform
