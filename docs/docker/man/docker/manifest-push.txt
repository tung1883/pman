       NAME

       docker manifest push - Push a manifest list to a repository

       DOCKER MANIFEST PUSH

       Push a manifest list to a repository

       USAGE

         docker manifest push [OPTIONS] MANIFEST_LIST

       OPTIONS

        * --insecure (bool): Allow push to an insecure registry
        * --purge, -p (bool): Remove the local manifest list after push
