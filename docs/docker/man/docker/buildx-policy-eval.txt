       NAME

       docker buildx policy eval - Evaluate policy for a source

       DOCKER BUILDX POLICY EVAL

       Evaluate policy for a source

       USAGE

         docker buildx policy eval [OPTIONS] source

       OPTIONS

        * --fields (stringSlice): Fields to evaluate
        * --file, -f (string): Policy filename to evaluate [default: Dockerfile]
        * --platform (string): Target platform for policy evaluation
        * --print (bool): Print policy output
