       NAME

       docker buildx policy test - Run policy tests

       DOCKER BUILDX POLICY TEST

       Run policy tests

       USAGE

         docker buildx policy test <path>

       OPTIONS

        * --filename (string): Name of the Dockerfile to validate [default: Dockerfile]
        * --run (string): Run only tests with name containing this substring
