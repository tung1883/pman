       NAME

       docker context rm - Remove one or more contexts

       DOCKER CONTEXT RM

       Remove one or more contexts

       USAGE

         docker context rm CONTEXT [CONTEXT...]

       Aliases: docker context rm, docker context remove

       OPTIONS

        * --force, -f (bool): Force the removal of a context in use
