       NAME

       docker compose attach - Attach local standard input, output, and error streams to a service's running container

       DOCKER COMPOSE ATTACH

       Attach local standard input, output, and error streams to a service's running container

       USAGE

         docker compose attach [OPTIONS] SERVICE

       OPTIONS

        * --detach-keys (string): Override the key sequence for detaching from a container.
        * --index (int): index of the container if service has multiple replicas.
        * --no-stdin (bool): Do not attach STDIN
        * --sig-proxy (bool): Proxy all received signals to the process [default: true]
