       NAME

       docker kill - Kill one or more running containers

       DOCKER KILL

       USAGE

         docker kill [OPTIONS] CONTAINER [CONTAINER...]

       Aliases: docker container kill, docker kill

       OPTIONS

        * --signal, -s (string): Signal to send to the container
