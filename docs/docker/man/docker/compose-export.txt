       NAME

       docker compose export - Export a service container's filesystem as a tar archive

       DOCKER COMPOSE EXPORT

       Export a service container's filesystem as a tar archive

       USAGE

         docker compose export [OPTIONS] SERVICE

       OPTIONS

        * --index (int): index of the container if service has multiple replicas.
        * --output, -o (string): Write to a file, instead of STDOUT
