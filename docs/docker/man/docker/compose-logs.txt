       NAME

       docker compose logs - View output from containers

       DOCKER COMPOSE LOGS

       View output from containers

       USAGE

         docker compose logs [OPTIONS] [SERVICE...]

       DESCRIPTION

       Displays log output from services

       OPTIONS

        * --follow, -f (bool): Follow log output
        * --index (int): index of the container if service has multiple replicas
        * --no-color (bool): Produce monochrome output
        * --no-log-prefix (bool): Don't print prefix in logs
        * --since (string): Show logs since timestamp (e.g. 2013-01-02T13:23:37Z) or relative (e.g. 42m for 42 minutes)
        * --tail, -n (string): Number of lines to show from the end of the logs for each container [default: all]
        * --timestamps, -t (bool): Show timestamps
        * --until (string): Show logs before a timestamp (e.g. 2013-01-02T13:23:37Z) or relative (e.g. 42m for 42 minutes)
