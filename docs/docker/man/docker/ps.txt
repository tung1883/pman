       NAME

       docker ps - List containers

       DOCKER PS

       List containers

       USAGE

         docker ps [OPTIONS]

       Aliases: docker container ls, docker container list, docker container ps, docker ps

       OPTIONS

        * --all, -a (bool): Show all containers (default shows just running)
        * --filter, -f (filter): Filter output based on conditions provided
        * --format (string): Format output using a custom template: 'table': Print output in table format with column headers (default) 'table TEMPLATE': Print output in table format using the given Go template 'json': Print in JSON format 'TEMPLATE': Print output using the given Go template. Refer to https://docs.docker.com/go/formatting/ for more information about formatting output with templates
        * --last, -n (int): Show n last created containers (includes all states) [default: -1]
        * --latest, -l (bool): Show the latest created container (includes all states)
        * --no-trunc (bool): Don't truncate output
        * --quiet, -q (bool): Only display container IDs
        * --size, -s (bool): Display total file sizes
