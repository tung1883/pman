       NAME

       docker compose port - List port mappings or print the public port for a specific mapping for the service

       DOCKER COMPOSE PORT

       List port mappings or print the public port for a specific mapping for the service

       USAGE

         docker compose port [OPTIONS] SERVICE [PRIVATE_PORT]

       OPTIONS

        * --index (int): Index of the container if service has multiple replicas
        * --protocol (string): tcp or udp [default: tcp]
