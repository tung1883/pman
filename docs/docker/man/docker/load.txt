       NAME

       docker load - Load an image from a tar archive or STDIN

       DOCKER LOAD

       Load an image from a tar archive or STDIN

       USAGE

         docker load [OPTIONS]

       Aliases: docker image load, docker load

       OPTIONS

        * --input, -i (string): Read from tar archive file, instead of STDIN
        * --platform (stringSlice): Load only the given platform(s). Formatted as a comma-separated list of os[/arch[/variant]] (e.g., linux/amd64,linux/arm64/v8).
        * --quiet, -q (bool): Suppress the load output
