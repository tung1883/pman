       NAME

       docker buildx debug - Start debugger

       DOCKER BUILDX DEBUG

       Start debugger

       OPTIONS

        * --invoke (string): Launch a monitor with executing specified command
        * --on (string): When to launch the monitor ([always, error]) [default: error]
