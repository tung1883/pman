       NAME

       docker container inspect - Display detailed information on one or more containers

       DOCKER CONTAINER INSPECT

       Display detailed information on one or more containers

       USAGE

         docker container inspect [OPTIONS] CONTAINER [CONTAINER...]

       OPTIONS

        * --format, -f (string): Format output using a custom template: 'json': Print in JSON format 'TEMPLATE': Print output using the given Go template. Refer to https://docs.docker.com/go/formatting/ for more information about formatting output with templates
        * --size, -s (bool): Display total file sizes
