       NAME

       docker compose watch - Watch build context for service and rebuild/refresh containers when files are updated

       DOCKER COMPOSE WATCH

       Watch build context for service and rebuild/refresh containers when files are updated

       USAGE

         docker compose watch [SERVICE...]

       OPTIONS

        * --no-up (bool): Do not build & start services before watching
        * --prune (bool): Prune dangling images on rebuild [default: true]
        * --quiet (bool): hide build output
