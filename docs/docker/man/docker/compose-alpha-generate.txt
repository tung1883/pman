       NAME

       docker compose alpha generate - EXPERIMENTAL - Generate a Compose file from existing containers

       DOCKER COMPOSE ALPHA GENERATE

       EXPERIMENTAL - Generate a Compose file from existing containers

       USAGE

         docker compose alpha generate [OPTIONS] [CONTAINERS...]

       OPTIONS

        * --format (string): Format the output. Values: [yaml | json] [default: yaml]
        * --name (string): Project name to set in the Compose file
        * --project-dir (string): Directory to use for the project
