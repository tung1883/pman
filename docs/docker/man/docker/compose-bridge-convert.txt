       NAME

       docker compose bridge convert - Convert compose files to Kubernetes manifests, Helm charts, or another model

       DOCKER COMPOSE BRIDGE CONVERT

       Convert compose files to Kubernetes manifests, Helm charts, or another model

       USAGE

         docker compose bridge convert

       OPTIONS

        * --output, -o (string): The output directory for the Kubernetes resources [default: out]
        * --templates (string): Directory containing transformation templates
        * --transformation, -t (stringArray): Transformation to apply to compose model (default: docker/compose-bridge-kubernetes)
        * --yes, -y (bool): Assume "yes" to the output directory overwrite prompt. For scripts/CI, where no interactive confirmation is possible
