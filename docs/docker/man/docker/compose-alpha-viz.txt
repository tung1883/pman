       NAME

       docker compose alpha viz - EXPERIMENTAL - Generate a graphviz graph from your compose file

       DOCKER COMPOSE ALPHA VIZ

       EXPERIMENTAL - Generate a graphviz graph from your compose file

       USAGE

         docker compose alpha viz [OPTIONS]

       OPTIONS

        * --image (bool): Include service's image name in output graph
        * --indentation-size (int): Number of tabs or spaces to use for indentation [default: 1]
        * --networks (bool): Include service's attached networks in output graph
        * --ports (bool): Include service's exposed ports in output graph
        * --spaces (bool): If given, space character ' ' will be used to indent, otherwise tab character '\t' will be used
