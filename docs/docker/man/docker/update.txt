       NAME

       docker update - Update configuration of one or more containers

       DOCKER UPDATE

       Update configuration of one or more containers

       USAGE

         docker update [OPTIONS] CONTAINER [CONTAINER...]

       Aliases: docker container update, docker update

       OPTIONS

        * --blkio-weight (uint16): Block IO (relative weight), between 10 and 1000, or 0 to disable (default 0)
        * --cpu-period (int64): Limit CPU CFS (Completely Fair Scheduler) period
        * --cpu-quota (int64): Limit CPU CFS (Completely Fair Scheduler) quota
        * --cpu-rt-period (int64): Limit the CPU real-time period in microseconds
        * --cpu-rt-runtime (int64): Limit the CPU real-time runtime in microseconds
        * --cpu-shares, -c (int64): CPU shares (relative weight)
        * --cpus (decimal): Number of CPUs
        * --cpuset-cpus (string): CPUs in which to allow execution (0-3, 0,1)
        * --cpuset-mems (string): MEMs in which to allow execution (0-3, 0,1)
        * --memory, -m (bytes): Memory limit
        * --memory-reservation (bytes): Memory soft limit
        * --memory-swap (bytes): Swap limit equal to memory plus swap: -1 to enable unlimited swap
        * --pids-limit (int64): Tune container pids limit (set -1 for unlimited)
        * --restart (string): Restart policy to apply when a container exits
