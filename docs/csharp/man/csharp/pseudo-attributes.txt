       CUSTOM ATTRIBUTES THAT GENERATE FLAGS OR OPTIONS IN THE INTERMEDIATE L

       Add these attributes to your code for the compiler to emit a specified Intermediate Language (IL) modifier. These attributes instruct the compiler to include the corresponding IL modifier in the output.

         Attribute  |  Modifier  |  Comments
         ComImportAttribute  |  import
         DllImportAttribute  |  pinvokeimpl  |  You can add options listed in the constructor.
         FieldOffsetAttribute  |  .field  |  This sets the field offset for memory layout.
         MarshalAsAttribute  |  marshal  |  You can set options listed in the constructor.
         MethodImplAttribute  |  flag  |  Constructor arguments specify specific named flags such as aggressiveinlining or forwardref. These flags also specify the native, managed, or optil modifiers for the MethodCodeType field.
         NonSerializedAttribute  |  notserialized
         OptionalAttribute  |  [opt]
         PreserveSigAttribute  |  preservesig
         SerializableAttribute  |  serializable
         StructLayoutAttribute  |  auto, sequential, or explicit  |  Layout options can be set using the parameters.
         IndexerNameAttribute  |  Add this attribute to an indexer to set a different method name. By default, indexers are compiled to a property named Item. You can specify a different name using this attribute.
       > The [StructLayoutAttribute] can't be combined with the ExtendedLayout attribute.
       Some of these custom attributes are applied by using other C# syntax rather than adding the attribute to your source code.

         Attribute  |  Comments
         DefaultParameterValueAttribute  |  Specifies the default value for the parameter. Use the default parameter syntax.
         InAttribute  |  Specifies the IL [in] modifier. Use the in or ref readonly modifiers.
         OutAttribute  |  Specifies the IL [out] modifier. Use the out modifier.
         SpecialNameAttribute  |  Specifies the IL specialname modifier. The compiler automatically adds this modifier for methods that require it.
         UnmanagedCallersOnlyAttribute  |  This attribute is required for the delegate* feature. The compiler adds it to any delegate* that requires its use. However, you must add this attribute to any method declaration when that method is assigned to a function pointer.
       The following attributes are generally disallowed in C# source. They're listed here to aid library authors who use reflection, and to ensure you don't create custom attributes with the same fully qualified name.

         Attribute  |  Comments
         CompilerFeatureRequiredAttribute  |  Prevents downlevel compilers from using metadata they can't safely understand.
         DecimalConstantAttribute  |  Encodes const decimal fields. The runtime doesn't support decimal values as constant values.
         DefaultMemberAttribute  |  Encodes indexers with IndexerNameAttribute. This attribute notes the default indexer when its name is different than Item. This attribute is allowed in source.
         DynamicAttribute  |  Encodes whether a type in a signature is dynamic (versus object).
         ExtensionAttribute  |  This attribute notes extension methods. The compiler also places this attribute on the containing classes.
         FixedBufferAttribute  |  This attribute specifies fixed struct fields.
         IsByRefLikeAttribute  |  This attribute specifies a ref struct.
         IsReadOnlyAttribute  |  This attribute indicates that a parameter has the in modifier. It distinguishes in parameters from readonly ref or [In] ref.
         RequiresLocationAttribute  |  This attribute indicates that a parameter has the readonly ref modifier. It distinguishes readonly ref from in or [In] ref.
         IsUnmanagedAttribute  |  This attribute specifies the unmanaged constraint on a type parameter.
         NullableAttribute, NullableContextAttribute, NullablePublicOnlyAttribute  |  These attributes encode nullable annotations in your source code.
         ParamArrayAttribute  |  This attribute encodes the params modifier on array parameters.
         ParamCollectionAttribute  |  This attribute encodes the params modifier on non-array parameters.
         RefSafetyRulesAttribute  |  This attribute specifies the C# version that is required in order to understand ref safety annotations in the assembly. Ref safety rules evolve as C# gets new features.
         RequiredMemberAttribute  |  This attribute indicates that the required modifier was placed on a member declaration. It's the encoding of the required members language feature.
         TupleElementNamesAttribute  |  This attribute encodes tuple element names used in signatures.
       In addition, the compiler can generate a declaration for other attributes used internally. The compiler generates these attributes in the CompilerServices namespace for its own use. Some aren't in the .NET Runtime libraries. Instead, the compiler synthesizes a definition for an internal type declaration in any assembly where the attribute is needed.
