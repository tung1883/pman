WEBAPI.ERROREVENT-FILENAME(1)    Sandbox manual    WEBAPI.ERROREVENT-FILENAME(1)

       NAME

       ErrorEvent: filename property - The filename read-only property of the ErrorEvent interface returns a string containing the name of the script file in which the error occur

       ERROREVENT: FILENAME PROPERTY

       The filename read-only property of the ErrorEvent interface returns a string containing the name of the script file in which the error occurred.

       VALUE

       A string.

       EXAMPLES

         window.addEventListener("error", (ev) => {
           console.log(`The error occur in file: ${ev.filename}`);
         });
