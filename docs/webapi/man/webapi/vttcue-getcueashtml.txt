WEBAPI.VTTCUE-GETCUEASHTML(1)    Sandbox manual    WEBAPI.VTTCUE-GETCUEASHTML(1)

       NAME

       VTTCue: getCueAsHTML() method - The getCueAsHTML() method of the VTTCue interface returns a DocumentFragment containing the cue content.

       VTTCUE: GETCUEASHTML() METHOD

       The getCueAsHTML() method of the VTTCue interface returns a DocumentFragment containing the cue content.

       SYNTAX

         getCueAsHTML()

       PARAMETERS

       None.

       RETURN VALUE

       A DocumentFragment.

       EXAMPLES

       In the following example a new VTTCue is created. The value as a document fragment is then printed to the console.

         let video = document.querySelector("video");
         let track = video.addTextTrack("captions", "Captions", "en");
         track.mode = "showing";

         let cue = new VTTCue(0, 0.9, "Hildy!");
         console.log(cue.getCueAsHTML());

         track.addCue(cue);
