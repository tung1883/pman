       NAME

       Navigator: appName property - The value of the Navigator.appName property is always

       NAVIGATOR: APPNAME PROPERTY

       The value of the Navigator.appName property is always "Netscape", in any browser. This property is kept only for compatibility purposes.

       > Do not rely on this property to return a real browser name. All browsers return "Netscape" as the value of this property.

       VALUE

       The string "Netscape".
