WEBAPI.LAYOUTSHIFTATTRIBUTION-NODE(1) Sandbox manual WEBAPI.LAYOUTSHIFTATTRIBUTION-NODE(1)

       NAME

       LayoutShiftAttribution: node property - The node read-only property of the LayoutShiftAttribution interface returns a Node representing the object that has shifted.

       LAYOUTSHIFTATTRIBUTION: NODE PROPERTY

       The node read-only property of the LayoutShiftAttribution interface returns a Node representing the object that has shifted.

       VALUE

       A Node.

       EXAMPLES

       The following example prints the node of the first item in LayoutShift.sources to the console.

         new PerformanceObserver((list) => {
           for (const { sources } of list.getEntries()) {
             if (sources) {
               console.log(sources[0].node);
             }
           }
         }).observe({ type: "layout-shift", buffered: true });
