       NAME

       SVGFECompositeElement: operator property - The operator read-only property of the SVGFECompositeElement interface reflects the operator attribute of the given feComposite element.

       SVGFECOMPOSITEELEMENT: OPERATOR PROPERTY

       The operator read-only property of the SVGFECompositeElement interface reflects the operator attribute of the given feComposite element.

       VALUE

       An SVGAnimatedEnumeration object.

       EXAMPLES

       Using out, in and over operators in feComposite element.
