WEBAPI.ERROREVENT-MESSAGE(1)     Sandbox manual     WEBAPI.ERROREVENT-MESSAGE(1)

       NAME

       ErrorEvent: message property - The message read-only property of the ErrorEvent interface returns a string containing a human-readable error message describing the problem

       ERROREVENT: MESSAGE PROPERTY

       The message read-only property of the ErrorEvent interface returns a string containing a human-readable error message describing the problem.

       VALUE

       A string.

       EXAMPLES

         window.addEventListener("error", (ev) => {
           console.log(`The error message: ${ev.message}`);
         });
