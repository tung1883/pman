WEBAPI.WORKERLOCATION-PATHNAME(1) Sandbox manual WEBAPI.WORKERLOCATION-PATHNAME(1)

       NAME

       WorkerLocation: pathname property - worker

       WORKERLOCATION: PATHNAME PROPERTY

       worker

       The pathname property of a WorkerLocation object returns the pathname part of the worker's location.

       VALUE

       A string.

       EXAMPLES

         // In a Web worker, on the page https://developer.mozilla.org/en-US/docs/Web
         const result = location.pathname; // Returns '/en-US/docs/Web'
