WEBAPI.MEDIADEVICEINFO-TOJSON(1) Sandbox manual WEBAPI.MEDIADEVICEINFO-TOJSON(1)

       NAME

       MediaDeviceInfo: toJSON() method - The toJSON() method of the MediaDeviceInfo interface is a serializer; it returns a JSON representation of the MediaDeviceInfo object.

       MEDIADEVICEINFO: TOJSON() METHOD

       The toJSON() method of the MediaDeviceInfo interface is a serializer; it returns a JSON representation of the MediaDeviceInfo object.

       SYNTAX

         toJSON()

       PARAMETERS

       None.

       RETURN VALUE

       A JSON object that is the serialization of the MediaDeviceInfo object.

       EXAMPLES

         if (!navigator.mediaDevices || !navigator.mediaDevices.enumerateDevices) {
           console.log("enumerateDevices() not supported.");
         } else {
           // List cameras and microphones.
           navigator.mediaDevices
             .enumerateDevices()
             .then((devices) => {
               devices.forEach((device) => {
                 console.log(device.toJSON());
               });
             })
             .catch((err) => {
               console.log(`${err.name}: ${err.message}`);
             });
         }
