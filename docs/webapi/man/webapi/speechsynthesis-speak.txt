       NAME

       SpeechSynthesis: speak() method - The speak() method of the SpeechSynthesis

       SPEECHSYNTHESIS: SPEAK() METHOD

       The speak() method of the SpeechSynthesis interface adds an utterance to the utterance queue; it will be spoken when any other utterances queued before it have been spoken.

       SYNTAX

         speak(utterance)

       PARAMETERS

        * utterance
          * : A SpeechSynthesisUtterance object.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       This snippet is excerpted from our Speech synthesizer demo (see it live). When a form containing the text we want to speak is submitted, we (among other things) create a new utterance containing this text, then speak it by passing it into speak() as a parameter.

         const synth = window.speechSynthesis;

         // …

         inputForm.onsubmit = (event) => {
           event.preventDefault();

           const utterThis = new SpeechSynthesisUtterance(inputTxt.value);
           const selectedOption =
             voiceSelect.selectedOptions[0].getAttribute("data-name");
           for (const voice of voices) {
             if (voice.name === selectedOption) {
               utterThis.voice = voice;
             }
           }
           synth.speak(utterThis);
           inputTxt.blur();
         };
