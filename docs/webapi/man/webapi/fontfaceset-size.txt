       NAME

       FontFaceSet: size property - The size read-only property of the FontFaceSet interface returns the number of items in the FontFaceSet.

       FONTFACESET: SIZE PROPERTY

       The size read-only property of the FontFaceSet interface returns the number of items in the FontFaceSet.

       VALUE

       An integer indicating the number of items in the FontFaceSet.

       EXAMPLES

       In the following example the size of the FontFaceSet is printed to the console.

         console.log(document.fonts.size);
