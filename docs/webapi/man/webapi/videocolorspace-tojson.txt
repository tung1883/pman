       NAME

       VideoColorSpace: toJSON() method - windowanddedicated

       VIDEOCOLORSPACE: TOJSON() METHOD

       window_and_dedicated

       The toJSON() method of the VideoColorSpace interface is a _serializer_ that returns a JSON representation of the VideoColorSpace object.

       SYNTAX

         toJSON()

       PARAMETERS

       None.

       RETURN VALUE

       A JSON object.

       EXAMPLES

       In the following example, colorSpace is a VideoColorSpace object returned from VideoFrame. This object is then printed to the console as JSON.

         let colorSpace = VideoFrame.colorSpace;
         console.log(colorSpace.toJSON());
