       HTMLSELECTELEMENT: AUTOCOMPLETE PROPERTY

       The autocomplete property of the HTMLSelectElement interface indicates whether the value of the control can be automatically completed by the browser. It reflects the element's autocomplete attribute.

       VALUE

       A string representing the value of the autocomplete attribute ("on", "off", or a ) or the empty string ("") if unspecified.

       EXAMPLES

         const selectElement = document.getElementById("favorite-fruit");
         console.log(textArea.autocomplete);
