       HTMLMETERELEMENT: VALUE PROPERTY

       The value property of the HTMLMeterElement interface represents the current value of the element as a floating-point number. It reflects the element's value attribute. If no value is set, it is the HTMLMeterElement.min value or 0, whichever is greater.

       This property can also be set directly, for example to set a default value based on some condition.

       VALUE

       A number. Defaults to either HTMLMeterElement.min or 0, whichever if greater, if not defined.

       EXAMPLES

         <label for="fuel">Current fuel level:</label>
         <meter
           id="fuel"
           min="0"
           max="100"
           low="15"
           high="66"
           optimum="80"
           value="50"></meter>

         const meterElement = document.getElementById("fuel");
         console.log(meterElement.value); // 50
         --meterElement.value;
         console.log(meterElement.value); // 49
