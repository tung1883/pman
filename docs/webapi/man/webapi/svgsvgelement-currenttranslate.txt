       SVGSVGELEMENT: CURRENTTRANSLATE PROPERTY

       The currentTranslate read-only property of the SVGSVGElement interface reflects the translation factor that takes into account user "magnification" corresponding to an outermost svg element.

       If the svg element is not at the outermost level, then currentTranslate is always { x: 0, y: 0 } and is read-only. Otherwise, it is writable.

       VALUE

       A DOMPointReadOnly.
