       NAME

       HTMLTextAreaElement: type property - The type read-only property of the HTMLTextAreaElement interface returns the string "textarea".

       HTMLTEXTAREAELEMENT: TYPE PROPERTY

       The type read-only property of the HTMLTextAreaElement interface returns the string "textarea".

       VALUE

       The string "textarea".

       EXAMPLE

         const textArea = document.querySelector("textarea");
         console.log(textArea.type); // "textarea"
