       NAME

       HTMLTextAreaElement: cols property - The cols property of the HTMLTextAreaElement interface is a positive integer representing the visible width of the multi-line text control, 

       HTMLTEXTAREAELEMENT: COLS PROPERTY

       The cols property of the HTMLTextAreaElement interface is a positive integer representing the visible width of the multi-line text control, in average character widths. It reflects the element's cols attribute.

       VALUE

       A positive integer. Defaults to 20.

       EXAMPLES

         const textareaElement = document.getElementById("comment");
         textArea.cols = 80;
