       NAME

       HTMLTrackElement: track property - The track read-only property of the HTMLTrackElement interface returns a TextTrack object corresponding to the text track of the <track> ele

       HTMLTRACKELEMENT: TRACK PROPERTY

       The track read-only property of the HTMLTrackElement interface returns a TextTrack object corresponding to the text track of the element.

       VALUE

       A TextTrack object.

       EXAMPLE

         const trackElement = document.getElementById("exampleTrack");
         console.dir(trackElement.track);
