       NAME

       SpeechSynthesisUtterance: end event - The end event of the Web Speech API SpeechSynthesisUtterance object is fired when the utterance has finished being spoken.

       SPEECHSYNTHESISUTTERANCE: END EVENT

       The end event of the Web Speech API SpeechSynthesisUtterance object is fired when the utterance has finished being spoken.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("end", (event) => { })

         onend = (event) => { }

       EVENT TYPE

       A SpeechSynthesisEvent. Inherits from Event.

       SpeechSynthesisEvent

       EXAMPLES

       You can use the end event in an addEventListener method:

         utterThis.addEventListener("end", (event) => {
           console.log(
             `Utterance has finished being spoken after ${event.elapsedTime} seconds.`,
           );
         });

       Or use the onend event handler property:

         utterThis.onend = (event) => {
           console.log(
             `Utterance has finished being spoken after ${event.elapsedTime} seconds.`,
           );
         };
