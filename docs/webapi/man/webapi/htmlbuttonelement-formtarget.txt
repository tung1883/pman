       HTMLButtonElement: formTarget property - The formTarget property of the HTMLButtonElement interface is the tab, window, or iframe where the response of the submitted <form> is to be

       HTMLBUTTONELEMENT: FORMTARGET PROPERTY

       The formTarget property of the HTMLButtonElement interface is the tab, window, or iframe where the response of the submitted is to be displayed. It reflects the value of the element's formtarget attribute.

       The value overrides the target property of the HTMLFormElement interface if the form is submitted via the button. This property can be retrieved or set. If not set, the value is the empty string ("").

       VALUE

       A string.

       EXAMPLES

         btnEl.formTarget = "_self";
