       HTMLMENUELEMENT

       The HTMLMenuElement interface provides additional properties (beyond those inherited from the HTMLElement interface) for manipulating a element. is a semantic alternative to the element.

       INSTANCE PROPERTIES

       _Inherits properties from its parent, HTMLElement, and its ancestors._

        * HTMLMenuElement.compact (deprecated)
          * : A boolean determining if the menu displays compactly.

       INSTANCE METHODS

       _Inherits methods from its parent, HTMLElement, and its ancestors._

       _HTMLMenuElement doesn't implement specific methods._
