       NAME

       HTMLSelectElement: required property - The required property of the HTMLSelectElement interface specifies that the user must select an option with a non-empty string value before 

       HTMLSELECTELEMENT: REQUIRED PROPERTY

       The required property of the HTMLSelectElement interface specifies that the user must select an option with a non-empty string value before submitting a form. It reflects the element's required attribute.

       VALUE

       A boolean.

       EXAMPLES

         const selectElement = document.getElementById("fruits");
         console.log(selectElement.required);
