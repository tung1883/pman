       NAME

       RTCIceParameters: password property - The RTCIceParameters

       RTCICEPARAMETERS: PASSWORD PROPERTY

       The RTCIceParameters dictionary's password property specifies the ICE password that, in tandem with the usernameFragment, uniquely identifies an ICE session for its entire duration.

       VALUE

       A string containing the password that corresponds to the transport's usernameFragment string
