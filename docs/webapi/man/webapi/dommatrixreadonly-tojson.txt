       DOMMATRIXREADONLY: TOJSON() METHOD

       The toJSON() method of the DOMMatrixReadOnly interface creates and returns a JSON object. The JSON object includes the 2D matrix elements a through f, the 16 elements of the 4X4 3D matrix, m1-4, the boolean is2D property, and the boolean isIdentity property.

       SYNTAX

         toJSON()

       PARAMETERS

       None.

       RETURN VALUE

       A JSON object; a JSON representation of the DOMMatrixReadOnly object.

       EXAMPLES
