       NAME

       HTMLEmbedElement: getSVGDocument() method - The getSVGDocument() method of the HTMLEmbedElement interface returns the Document object of the embedded SVG.

       HTMLEMBEDELEMENT: GETSVGDOCUMENT() METHOD

       The getSVGDocument() method of the HTMLEmbedElement interface returns the Document object of the embedded SVG.

       SYNTAX

         getSVGDocument()

       PARAMETERS

       None.

       RETURN VALUE

       A Document.

       EXAMPLES

         const svg = document.getElementById("el").getSVGDocument();
