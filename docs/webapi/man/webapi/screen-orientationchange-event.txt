       NAME

       Screen: orientationchange event - The orientationchange event fires when the device's orientation has changed.

       SCREEN: ORIENTATIONCHANGE EVENT

       {{Non-standard_Header}}

       The orientationchange event fires when the device's orientation has changed.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("orientationchange", (event) => { })

         onorientationchange = (event) => { }

       EVENT TYPE

       A generic Event.

       SPECIFICATIONS

       This feature is not part of any specification. It is no longer on track to becoming a standard.

       Use the ScreenOrientation change event instead.
