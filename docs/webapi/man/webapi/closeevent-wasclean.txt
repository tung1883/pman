WEBAPI.CLOSEEVENT-WASCLEAN(1)    Sandbox manual    WEBAPI.CLOSEEVENT-WASCLEAN(1)

       NAME

       CloseEvent: wasClean property - The wasClean read-only property of the CloseEvent interface returns true if the connection closed cleanly.

       CLOSEEVENT: WASCLEAN PROPERTY

       The wasClean read-only property of the CloseEvent interface returns true if the connection closed cleanly.

       VALUE

       A boolean value. True if the connection closed cleanly, false otherwise.

       EXAMPLES

       The following example prints the value of wasClean to the console.

         WebSocket.onclose = (event) => {
           console.log(event.wasClean);
         };
