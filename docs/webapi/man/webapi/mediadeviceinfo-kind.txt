       NAME

       MediaDeviceInfo: kind property - The kind read-only property of

       MEDIADEVICEINFO: KIND PROPERTY

       The kind read-only property of the MediaDeviceInfo interface returns an enumerated value, that is either "videoinput", "audioinput" or "audiooutput".

       VALUE

       One of "videoinput", "audioinput" or "audiooutput".
