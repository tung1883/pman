       NAME

       MediaKeySystemAccess: keySystem property - The keySystem read-only property of the MediaKeySystemAccess interface returns a string identifying the key system being used.

       MEDIAKEYSYSTEMACCESS: KEYSYSTEM PROPERTY

       The keySystem read-only property of the MediaKeySystemAccess interface returns a string identifying the key system being used.

       This is the value that was passed to Navigator.requestMediaKeySystemAccess() when system access is requested.

       VALUE

       A string.
