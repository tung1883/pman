       NAME

       CSSTransformValue: values() method - The values() method of the CSSTransformValue interface returns a new array iterator that yields each item in the object.

       CSSTRANSFORMVALUE: VALUES() METHOD

       The values() method of the CSSTransformValue interface returns a new _array iterator_ that yields each item in the object.

       SYNTAX

         values()

       PARAMETERS

       None.

       RETURN VALUE

       A new iterable iterator object.

       EXAMPLES

       ITERATING OVER VALUES

         const transform = new CSSTransformValue([
           new CSSTranslate(CSS.px(10), CSS.px(20)),
           new CSSScale(2, 3),
         ]);

         for (const component of transform.values()) {
           console.log(component.toString());
         }
         // "translate(10px, 20px)"
         // "scale(2, 3)"
