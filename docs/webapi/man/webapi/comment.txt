       COMMENT

       The Comment interface represents textual notations within markup; although it is generally not visually shown, such comments are available to be read in the source view.

       Comments are represented in HTML and XML as content between . In XML, like inside SVG or MathML markup, the character sequence -- cannot be used within a comment.

       INSTANCE PROPERTIES

       _This interface has no specific property, but inherits those of its parent, CharacterData, and indirectly those of Node._

       CONSTRUCTOR

        * Comment()
          * : Returns a new Comment object with the parameter as its textual content. If not present, its default value is the empty string, ''.

       INSTANCE METHODS

       _This interface has no specific method, but inherits those of its parent, CharacterData, and indirectly those of Node._
