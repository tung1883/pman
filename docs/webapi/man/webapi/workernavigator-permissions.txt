WEBAPI.WORKERNAVIGATOR-PERMISSIONS(1) Sandbox manual WEBAPI.WORKERNAVIGATOR-PERMISSIONS(1)

       NAME

       WorkerNavigator: permissions property - worker

       WORKERNAVIGATOR: PERMISSIONS PROPERTY

       worker

       The permissions read-only property of the WorkerNavigator interface returns a Permissions object that can be used to query and update permission status of APIs covered by the Permissions API.

       VALUE

       A Permissions object.

       EXAMPLES

         navigator.permissions.query({ name: "notifications" }).then((result) => {
           if (result.state === "granted") {
             showNotification();
           } else if (result.state === "prompt") {
             requestNotificationPermission();
           }
         });
