WEBAPI.MEDIAENCRYPTEDEVENT-INITDATA(1) Sandbox manual WEBAPI.MEDIAENCRYPTEDEVENT-INITDATA(1)

       NAME

       MediaEncryptedEvent: initData property - The read-only initData property of the MediaKeyMessageEvent returns the initialization data contained in this event, if any.

       MEDIAENCRYPTEDEVENT: INITDATA PROPERTY

       The read-only initData property of the MediaKeyMessageEvent returns the initialization data contained in this event, if any.

       VALUE

       An ArrayBuffer with the initialization data, or null if there are none.
