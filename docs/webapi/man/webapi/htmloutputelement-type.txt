       NAME

       HTMLOutputElement: type property - The type read-only property of the HTMLOutputElement interface returns the string "output".

       HTMLOUTPUTELEMENT: TYPE PROPERTY

       The type read-only property of the HTMLOutputElement interface returns the string "output".

       VALUE

       The string "output".

       EXAMPLE

         const output = document.querySelector("output");
         console.log(output.type); // "output"
