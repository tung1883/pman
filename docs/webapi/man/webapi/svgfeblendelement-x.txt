       NAME

       SVGFEBlendElement: x property - The x read-only property of the SVGFEBlendElement interface describes the horizontal coordinate of the position of an SVG filter primitive a

       SVGFEBLENDELEMENT: X PROPERTY

       The x read-only property of the SVGFEBlendElement interface describes the horizontal coordinate of the position of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feBlend element's x filter primitive attribute value. The SVG filter blends two input images together using commonly used imaging software blending modes.

       The attribute is a or . The is a length in the user coordinate system that is the given distance from the origin of the user coordinate system along the x-axis. If the x attribute is a percent value, the property value is relative to the width of the filter region in user coordinate system units. The default value is 0.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feBlend = document.querySelector("feBlend");
         const leftPosition = feBlend.x;
         console.log(leftPosition.baseVal.value); // the `x` value
