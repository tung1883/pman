       NAME

       SVGFEPointLightElement: x property - The x read-only property of the SVGFEPointLightElement interface describes the horizontal coordinate of the position of an SVG filter primit

       SVGFEPOINTLIGHTELEMENT: X PROPERTY

       The x read-only property of the SVGFEPointLightElement interface describes the horizontal coordinate of the position of an SVG filter primitive as a SVGAnimatedNumber.

       It reflects the x attribute of the fePointLight element, which can be used to define the light source in a point light effect. The attribute is a . The default value is 0.

       VALUE

       An SVGAnimatedNumber.

       EXAMPLE

         const fePointLight = document.querySelector("fePointLight");
         const leftPosition = fePointLight.x;
         console.log(leftPosition.baseVal.value); // the `x` value
