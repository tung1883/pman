       SVGFECompositeElement: height property - The height read-only property of the SVGFECompositeElement interface describes the vertical size of an SVG filter primitive as a SVGAnimated

       SVGFECOMPOSITEELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFECompositeElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feComposite element's height filter primitive attribute. The SVG filter primitive combines two input images using a Porter-Duff compositing operation. The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feComposite = document.querySelector("feComposite");
         const verticalSize = feComposite.height;
         console.log(verticalSize.baseVal.value); // the `height` value
