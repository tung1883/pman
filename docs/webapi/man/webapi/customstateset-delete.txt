       NAME

       CustomStateSet: delete() method - The delete() method of the CustomStateSet interface deletes a single value from the CustomStateSet.

       CUSTOMSTATESET: DELETE() METHOD

       The delete() method of the CustomStateSet interface deletes a single value from the CustomStateSet.

       SYNTAX

         delete(value)

       PARAMETERS

        * value
          * : value to remove from the CustomStateSet.

       RETURN VALUE

       Returns true if value was in the CustomStateSet; otherwise false.
