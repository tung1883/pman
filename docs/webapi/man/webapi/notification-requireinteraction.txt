       NAME

       Notification: requireInteraction property - The requireInteraction read-only property of the Notification interface returns a boolean value indicating that a notification should remain

       NOTIFICATION: REQUIREINTERACTION PROPERTY

       The requireInteraction read-only property of the Notification interface returns a boolean value indicating that a notification should remain active until the user clicks or dismisses it, rather than closing automatically.

       > This can be set when the notification is first created by setting the requireInteraction option to true in the options object of the Notification() constructor.

       VALUE

       A boolean value.
