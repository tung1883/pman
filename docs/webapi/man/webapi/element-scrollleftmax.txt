       NAME

       Element: scrollLeftMax property - The Element.scrollLeftMax read-only property returns a

       ELEMENT: SCROLLLEFTMAX PROPERTY

       {{Non-standard_header}}

       The Element.scrollLeftMax read-only property returns a number representing the maximum left scroll offset possible for the element.

       VALUE

       A number.

       SPECIFICATIONS

       _This property is not part of any specification._

       BROWSER COMPATIBILITY

       SEE ALSO

        * Element.scrollTopMax giving the same information for the other axis.
