       NAME

       CanvasRenderingContext2D: canvas property - The CanvasRenderingContext2D.canvas property, part of the

       CANVASRENDERINGCONTEXT2D: CANVAS PROPERTY

       The CanvasRenderingContext2D.canvas property, part of the Canvas API, is a read-only reference to the HTMLCanvasElement object that is associated with a given context.

       VALUE

       A HTMLCanvasElement object.

       EXAMPLES

       Given this element:

         <canvas id="canvas"></canvas>

       … you can get a reference to the canvas element within the CanvasRenderingContext2D by using the canvas property:

         const canvas = document.getElementById("canvas");
         const ctx = canvas.getContext("2d");
         ctx.canvas; // HTMLCanvasElement
