       NAME

       HTMLTableRowElement: chOff property - The chOff property of the HTMLTableRowElement interface does nothing. It reflects the charoff attribute of the <tr> element.

       HTMLTABLEROWELEMENT: CHOFF PROPERTY

       The chOff property of the HTMLTableRowElement interface does nothing. It reflects the charoff attribute of the element.

       > This property was designed to participate in an ability to align table cell content on a specific character (typically the decimal point), but was never implemented by browsers.
       > To achieve such alignment, watch for the support of a string value with the text-align CSS property.

       VALUE

       An integer.
