       NAME

       HTMLFormElement: action property - The HTMLFormElement.action property represents the action

       HTMLFORMELEMENT: ACTION PROPERTY

       The HTMLFormElement.action property represents the action of the element.

       The action of a form is the program that is executed on the server when the form is submitted. This property can be retrieved or set.

       VALUE

       A string.

       EXAMPLES

         form.action = "/cgi-bin/publish";
