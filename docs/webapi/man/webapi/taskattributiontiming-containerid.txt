       NAME

       TaskAttributionTiming: containerId property - The containerId read-only property of the TaskAttributionTiming interface returns the container's id

       TASKATTRIBUTIONTIMING: CONTAINERID PROPERTY

       The containerId read-only property of the TaskAttributionTiming interface returns the container's id attribute. A container is the iframe, embed or object etc. that is being implicated, on the whole, for a long task.

       VALUE

       A string containing the container's id HTML content attribute.
