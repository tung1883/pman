       HTMLSELECTELEMENT: SIZE PROPERTY

       The size property of the HTMLSelectElement interface specifies the number of options, or rows, that should be visible at one time. It reflects the element's size attribute. If omitted, the value is 0.

       > While by default a displays a single row unless multiple is true, in which case four rows are displayed, the default value for the size property is 0.

       VALUE

       A number.

       EXAMPLES

         const selectElement = document.getElementById("fruits");
         console.log(selectElement.size);
