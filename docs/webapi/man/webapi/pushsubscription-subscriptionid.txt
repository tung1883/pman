       NAME

       PushSubscription: subscriptionId property - The subscriptionId read-only property of the

       PUSHSUBSCRIPTION: SUBSCRIPTIONID PROPERTY

       {{non-standard_header}}

       The subscriptionId read-only property of the PushSubscription interface returns a string containing the subscription ID associated with the push subscription.

       > Instead of this feature, use the PushSubscription.endpoint property on the same interface.

       VALUE

       A string.

       SPECIFICATIONS

       This feature was removed from the Push API specification. It is no longer on track to become a standard.
