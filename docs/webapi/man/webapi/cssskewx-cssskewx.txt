       NAME

       CSSSkewX: CSSSkewX() constructor - The CSSSkewX() constructor creates a new CSSSkewX object that represents the skewX() value of the individual transform property in CSS.

       CSSSKEWX: CSSSKEWX() CONSTRUCTOR

       The CSSSkewX() constructor creates a new CSSSkewX object that represents the skewX() value of the individual transform property in CSS.

       SYNTAX

         new CSSSkewX(ax)

       PARAMETERS

        * ax
          * : A value for the ax angle of the CSSSkewX object to be constructed.
       This must be a CSSNumericValue.
