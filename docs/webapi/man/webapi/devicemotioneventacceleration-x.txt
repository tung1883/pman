       NAME

       DeviceMotionEventAcceleration: x property - The x read-only property of the DeviceMotionEventAcceleration interface indicates the amount of acceleration that occurred along the X

       DEVICEMOTIONEVENTACCELERATION: X PROPERTY

       The x read-only property of the DeviceMotionEventAcceleration interface indicates the amount of acceleration that occurred along the X axis in a DeviceMotionEventAcceleration object.

       VALUE

       A double indicating the amount of acceleration along the X axis. See Accelerometer values explained for details.
