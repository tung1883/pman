       NAME

       HTMLFontElement - Implements the document object model (DOM) representation of the font element. The HTML Font Element <font> defines the font size, font face

       HTMLFONTELEMENT

       Implements the document object model (DOM) representation of the font element. The HTML Font Element defines the font size, font face and color of text.

       INSTANCE PROPERTIES

       _Inherits properties from its parent, HTMLElement._

        * HTMLFontElement.color (deprecated)
          * : A string that reflects the color HTML attribute, containing either a named color or a color specified in the hexadecimal #RRGGBB format.
        * HTMLFontElement.face (deprecated)
          * : A string that reflects the face HTML attribute, containing a comma-separated list of one or more font names.
        * HTMLFontElement.size (deprecated)
          * : A string that reflects the size HTML attribute, containing either a font size ranging from 1 to 7 or a number relative to the default value 3, for example -2 or +1.

       INSTANCE METHODS

       _No specific method; inherits methods from its parent, HTMLElement._
