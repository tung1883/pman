       HTMLPREELEMENT

       The HTMLPreElement interface exposes specific properties and methods (beyond those of the HTMLElement interface it also has available to it by inheritance) for manipulating a block of preformatted text ().

       INSTANCE PROPERTIES

       _Inherits properties from its parent, HTMLElement._

        * HTMLPreElement.width (deprecated)
          * : A long value reflecting the obsolete width attribute, containing a fixed-size length for the element.

       INSTANCE METHODS

       _No specific method; inherits methods from its parent, HTMLElement._
