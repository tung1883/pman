       NAME

       RTCCertificateStats: type property - The type property of the RTCCertificateStats dictionary is a string with the value "certificate".

       RTCCERTIFICATESTATS: TYPE PROPERTY

       The type property of the RTCCertificateStats dictionary is a string with the value "certificate".

       Different statistics are obtained by iterating the RTCStatsReport object returned by a call to RTCPeerConnection.getStats(). The type indicates the set of statistics available through the object in a particular iteration step. A value of "certificate" indicates that the statistics available in the current step are those defined in RTCCertificateStats.

       VALUE

       A string with the value "certificate".
