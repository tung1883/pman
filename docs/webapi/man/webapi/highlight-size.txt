       NAME

       Highlight: size property - The size property returns the number of AbstractRange objects in a

       HIGHLIGHT: SIZE PROPERTY

       The size property returns the number of AbstractRange objects in a Highlight object.

       VALUE

       The value of size is a read-only integer representing how many entries the highlight object has.

       EXAMPLES

       USING SIZE

         const highlight = new Highlight();
         highlight.add(range1);
         highlight.add(range2);
         highlight.add(range3);

         console.log(highlight.size); // 3
