       NAME

       PushManager: permissionState() method - The permissionState() method of the

       PUSHMANAGER: PERMISSIONSTATE() METHOD

       The permissionState() method of the PushManager interface returns a Promise that resolves to a string indicating the permission state of the push manager. Possible values are 'prompt', 'denied', or 'granted'.

       > As of Firefox 44, the permissions for Notifications and Push have been merged. If permission is
       > granted for notifications, push will also be enabled.

       SYNTAX

         permissionState()
         permissionState(options)

       PARAMETERS

        * options (optional)
          * : An object containing optional configuration parameters. It can have the following
       properties:

            * userVisibleOnly
              * : A boolean indicating that the returned push
       subscription will only be used for messages whose effect is made visible to the user.

            * applicationServerKey
              * : A public key your push server will use to
       send messages to client apps via a push server. This value is part of a signing key pair generated by your application server and usable with elliptic curve digital signature (ECDSA) over the P-256 curve.

       RETURN VALUE

       A Promise that resolves to a string with a value of 'prompt', 'denied', or 'granted'.
