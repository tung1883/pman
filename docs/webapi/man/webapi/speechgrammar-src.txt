       NAME

       SpeechGrammar: src property - The src property of the SpeechGrammar interface

       SPEECHGRAMMAR: SRC PROPERTY

       The src property of the SpeechGrammar interface is used to get or set a string that contains the grammar within the SpeechGrammar object.

       VALUE

       A string representing the grammar.
