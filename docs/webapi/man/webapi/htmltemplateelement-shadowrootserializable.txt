       NAME

       HTMLTemplateElement: shadowRootSerializable property - The shadowRootSerializable property reflects the value of the shadowrootserializable attribute of the associated <template> element.

       HTMLTEMPLATEELEMENT: SHADOWROOTSERIALIZABLE PROPERTY

       The shadowRootSerializable property reflects the value of the shadowrootserializable attribute of the associated element.

       > This property is not useful for developers, and is only documented for completeness.
       > If a element is used to declaratively create a ShadowRoot, then this object and property do not exist.
       > Otherwise, if an HTMLTemplateElement is created, the value of this property is irrelevant because the object is not a shadow root and cannot subsequently be changed to a shadow root.

       VALUE

       Reflects the value of the shadowrootserializable attribute of the associated element.
