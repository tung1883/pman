       HTMLFIELDSETELEMENT: DISABLED PROPERTY

       The disabled property of the HTMLFieldSetElement interface is a boolean value that reflects the element's disabled attribute, which indicates whether the control is disabled.

       When disabled, all the form control descendants of the element, excluding elements that are descendants of the child of the , if any, are disabled. A disabled element is unusable and un-clickable, and match the :disabled selector, even if their disabled property value is false.

       VALUE

       A boolean value.

       EXAMPLES

         const fs = document.getElementById("billing-address");
         console.log(fs.disabled);
         fs.disabled = true;
