       HTMLFIELDSETELEMENT: CHECKVALIDITY() METHOD

       The checkValidity() method of the HTMLFieldSetElement interface checks if the element is valid, but always returns true because elements are never candidates for constraint validation.

       > The :valid and :invalid CSS pseudo-classes are applied to elements based on the validity of its descendant form controls, not the fieldset itself.

       SYNTAX

         checkValidity()

       PARAMETERS

       None.

       RETURN VALUE

       A boolean value, true.

       EXAMPLES

       In the following example, calling checkValidity() returns true.

         const element = document.getElementById("myFieldSet");
         console.log(element.checkValidity());
