       NAME

       SVGFEComponentTransferElement: result property - The result read-only property of the SVGFEComponentTransferElement interface describes the assigned name of an SVG filter primitive as a SVG

       SVGFECOMPONENTTRANSFERELEMENT: RESULT PROPERTY

       The result read-only property of the SVGFEComponentTransferElement interface describes the assigned name of an SVG filter primitive as a SVGAnimatedString.

       It reflects the feComponentTransfer element's result attribute. The attribute value is a custom-ident. If supplied, then graphics that result from processing this filter primitive can be referenced by an in attribute on a subsequent filter primitive within the same filter element.

       If no result attribute is defined, the filter's result.baseVal and result.animVal are empty strings, and the output of the filter will only be available for re-use as the implicit input into the next filter primitive if that filter primitive provides no value for its in attribute.

       VALUE

       An SVGAnimatedString.

       EXAMPLE

         const feComponentTransferElement = document.querySelector(
           "feComponentTransfer",
         );
         const filterName = feComponentTransferElement.result;
         console.log(filterName.baseVal); // the filter's assigned name
