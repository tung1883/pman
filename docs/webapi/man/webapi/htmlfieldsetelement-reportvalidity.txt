       HTMLFIELDSETELEMENT: REPORTVALIDITY() METHOD

       The reportValidity() method of the HTMLFieldSetElement interface performs the same validity checking steps as the checkValidity() method. It always returns true because elements are never candidates for constraint validation.

       SYNTAX

         reportValidity()

       PARAMETERS

       None.

       RETURN VALUE

       A boolean value, true.
