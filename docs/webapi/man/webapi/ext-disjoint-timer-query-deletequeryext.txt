       NAME

       EXT_disjoint_timer_query: deleteQueryEXT() method - The EXTdisjointtimerquery.deleteQueryEXT() method of

       EXT_DISJOINT_TIMER_QUERY: DELETEQUERYEXT() METHOD

       The EXT_disjoint_timer_query.deleteQueryEXT() method of the WebGL API deletes a given WebGLQuery object.

       SYNTAX

         deleteQueryEXT(query)

       PARAMETERS

        * query
          * : A WebGLQuery object to delete.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         const ext = gl.getExtension("EXT_disjoint_timer_query");
         const query = ext.createQueryEXT();

         // …

         ext.deleteQueryEXT(query);
