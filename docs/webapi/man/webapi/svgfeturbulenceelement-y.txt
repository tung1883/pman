       NAME

       SVGFETurbulenceElement: y property - The y read-only property of the SVGFETurbulenceElement interface describes the vertical coordinate of the position of an SVG filter primitiv

       SVGFETURBULENCEELEMENT: Y PROPERTY

       The y read-only property of the SVGFETurbulenceElement interface describes the vertical coordinate of the position of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the y attribute of the feTurbulence element, which allows the synthesis of artificial textures. The attribute is a or . The is a length in the user coordinate system that is the given distance from the origin of the filter along the y-axis. If the y attribute is a percent value, the property value is a relative to the height of the filter region in user coordinate system units. The default value is 0.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feTurbulence = document.querySelector("feTurbulence");
         const topPosition = feTurbulence.y;
         console.log(topPosition.baseVal.value); // the `y` value
