       NAME

       Text: assignedSlot property - The read-only assignedSlot property of the Text interface

       TEXT: ASSIGNEDSLOT PROPERTY

       The read-only assignedSlot property of the Text interface returns the HTMLSlotElement object associated with the element.

       VALUE

       An HTMLSlotElement, or null if no element is associated with the text node.
