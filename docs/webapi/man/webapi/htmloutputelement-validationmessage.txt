       HTMLOutputElement: validationMessage property - The validationMessage read-only property of the HTMLOutputElement interface returns a string representing a localized message that describes

       HTMLOUTPUTELEMENT: VALIDATIONMESSAGE PROPERTY

       The validationMessage read-only property of the HTMLOutputElement interface returns a string representing a localized message that describes the validation constraints that the control does not satisfy (if any). This is the empty string as elements are not candidates for constraint validation (HTMLOutputElement.willValidate is false).

       VALUE

       The empty string, "";
