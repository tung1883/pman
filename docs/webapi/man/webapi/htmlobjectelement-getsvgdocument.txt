       NAME

       HTMLObjectElement: getSVGDocument() method - The getSVGDocument() method of the HTMLObjectElement interface returns the Document object of the embedded SVG.

       HTMLOBJECTELEMENT: GETSVGDOCUMENT() METHOD

       The getSVGDocument() method of the HTMLObjectElement interface returns the Document object of the embedded SVG.

       SYNTAX

         getSVGDocument()

       PARAMETERS

       None.

       RETURN VALUE

       A Document.

       EXAMPLES

         const svg = document.getElementById("el").getSVGDocument();
