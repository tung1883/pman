       NAME

       Keyboard: unlock() method - The unlock() method of the

       KEYBOARD: UNLOCK() METHOD

       The unlock() method of the Keyboard interface unlocks all keys captured by the Keyboard.lock() method and returns synchronously.

       SYNTAX

         unlock()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).
