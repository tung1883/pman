       NAME

       MediaStream: addTrack() method - The addTrack() method of the MediaStream interface adds a new track to the

       MEDIASTREAM: ADDTRACK() METHOD

       The addTrack() method of the MediaStream interface adds a new track to the stream. The track is specified as a parameter of type MediaStreamTrack.

       > If the specified track is already in the stream's track set, this method has no
       > effect.

       SYNTAX

         addTrack(track)

       PARAMETERS

        * track
          * : A MediaStreamTrack to add to the stream.

       RETURN VALUE

       None (undefined).
