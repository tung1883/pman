WEBAPI.CSSTRANSFORMVALUE-KEYS(1) Sandbox manual WEBAPI.CSSTRANSFORMVALUE-KEYS(1)

       NAME

       CSSTransformValue: keys() method - The keys() method of the CSSTransformValue interface returns a new array iterator that yields the index of each item in the object.

       CSSTRANSFORMVALUE: KEYS() METHOD

       The keys() method of the CSSTransformValue interface returns a new _array iterator_ that yields the index of each item in the object.

       SYNTAX

         keys()

       PARAMETERS

       None.

       RETURN VALUE

       A new iterable iterator object.

       EXAMPLES

       ITERATING OVER INDEXES

         const transform = new CSSTransformValue([
           new CSSTranslate(CSS.px(10), CSS.px(20)),
           new CSSScale(2, 3),
         ]);

         for (const index of transform.keys()) {
           console.log(index);
         }
         // 0
         // 1
