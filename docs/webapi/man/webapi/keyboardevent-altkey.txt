       NAME

       KeyboardEvent: altKey property - The KeyboardEvent.altKey read-only property is a

       KEYBOARDEVENT: ALTKEY PROPERTY

       The KeyboardEvent.altKey read-only property is a boolean value that indicates if the alt key (Option or ⌥ on macOS) was pressed (true) or not (false) when the event occurred.

       When the Alt key itself is pressed or released, this property is true for its keydown event and false for its keyup event, because both events fire _after_ the state change.

       VALUE

       A boolean value.

       EXAMPLES

         <p>
           Press any character key, with or without holding down the ALT key.<br />

         function showChar(e) {
           output.textContent = `Key KeyDown: "${e.key}"

         `;
         }

         document.addEventListener("keydown", showChar);
