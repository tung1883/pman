       NAME

       AnimationEvent: animationName property - The AnimationEvent.animationName read-only property is a

       ANIMATIONEVENT: ANIMATIONNAME PROPERTY

       The AnimationEvent.animationName read-only property is a string containing the value of the animation-name CSS property associated with the transition.

       VALUE

       A string containing the value of the animation-name CSS property.
