       SVGFETILEELEMENT: Y PROPERTY

       The y read-only property of the SVGFETileElement interface describes the vertical coordinate of the position of an SVG filter primitive as an SVGAnimatedLength.

       It reflects the y attribute of the feTile element, which fills a target rectangle with a repeated, tiled pattern of an input image. The attribute is a or . The is a length in the user coordinate system that is the given distance from the origin of the filter along the y-axis. If the y attribute is a percent value, the property value is a relative to the height of the filter region in user coordinate system units. The default value is 0.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feTile = document.querySelector("feTile");
         const topPosition = feTile.y;
         console.log(topPosition.baseVal.value); // the `y` value
