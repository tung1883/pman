       HTMLAREAELEMENT: SHAPE PROPERTY

       The shape property of the HTMLAreaElement interface specifies the shape of an image map area. It reflects the element's shape attribute.

       VALUE

       A string; rect, circle, or poly.

       EXAMPLES

         const areaElement = document.getElementById("imageMapArea");
         console.log(areaElement.shape);
