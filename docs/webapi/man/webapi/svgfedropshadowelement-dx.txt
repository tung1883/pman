WEBAPI.SVGFEDROPSHADOWELEMENT-DX(1) Sandbox manual WEBAPI.SVGFEDROPSHADOWELEMENT-DX(1)

       NAME

       SVGFEDropShadowElement: dx property - The dx read-only property of the SVGFEDropShadowElement interface reflects the dx attribute of the given feDropShadow element.

       SVGFEDROPSHADOWELEMENT: DX PROPERTY

       The dx read-only property of the SVGFEDropShadowElement interface reflects the dx attribute of the given feDropShadow element.

       VALUE

       An SVGAnimatedNumber object.

       EXAMPLES

       ACCESSING THE DX VALUE

       In this example, we retrieve the horizontal shift of the by using the dx read-only property of the SVGFEDropShadowElement interface.

         <svg viewBox="0 0 200 200" xmlns="http://www.w3.org/2000/svg">
           <defs>
             <filter id="drop-shadow-filter">
               <!-- Drop Shadow with dx property set to 10 -->
               <feDropShadow
                 in="SourceGraphic"
                 dx="10"
                 dy="10"
                 stdDeviation="5"
                 flood-color="red" />
             </filter>
           </defs>

           <!-- Rectangle with a red shadow -->
           <rect
             x="20"
             y="20"
             width="100"
             height="100"
             fill="red"
             filter="url(#drop-shadow-filter)" />

           <!-- Circle with a red shadow -->
           <circle
             cx="100"
             cy="100"
             r="50"
             fill="blue"
             filter="url(#drop-shadow-filter)" />
         </svg>

         const dropShadow = document.querySelector("feDropShadow");

         console.log(dropShadow.dx.baseVal); // Output: 10
