       NAME

       HTMLIFrameElement: getSVGDocument() method - The getSVGDocument() method of the HTMLIFrameElement interface returns the Document object of the embedded SVG.

       HTMLIFRAMEELEMENT: GETSVGDOCUMENT() METHOD

       The getSVGDocument() method of the HTMLIFrameElement interface returns the Document object of the embedded SVG.

       SYNTAX

         getSVGDocument()

       PARAMETERS

       None.

       RETURN VALUE

       A Document.

       EXAMPLES

         const svgDoc = document.getElementById("el").getSVGDocument();
