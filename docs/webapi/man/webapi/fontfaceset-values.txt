       FONTFACESET: VALUES() METHOD

       The values() method of the FontFaceSet interface returns a new iterator object that yields the values for each element in the FontFaceSet object in insertion order.

       SYNTAX

         values()

       PARAMETERS

       None.

       RETURN VALUE

       A new iterator object containing the values for each element in the given FontFaceSet, in insertion order.
