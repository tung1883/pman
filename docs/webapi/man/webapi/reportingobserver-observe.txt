       NAME

       ReportingObserver: observe() method - The observe() method of the ReportingObserver interface instructs a reporting observer to start collecting reports in its report queue.

       REPORTINGOBSERVER: OBSERVE() METHOD

       The observe() method of the ReportingObserver interface instructs a reporting observer to start collecting reports in its report queue.

       SYNTAX

         observe()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       BASIC USAGE

         const options = {
           types: ["deprecation"],
           buffered: true,
         };

         const observer = new ReportingObserver((reports, observer) => {
           reportBtn.onclick = () => displayReports(reports);
         }, options);

         observer.observe();
