       NAME

       SVGViewElement - The SVGViewElement interface provides access to the properties of view elements, as well as methods to manipulate them.

       SVGVIEWELEMENT

       The SVGViewElement interface provides access to the properties of view elements, as well as methods to manipulate them.

       INSTANCE PROPERTIES

       _This interface also inherits properties from its parent interface, SVGElement._

        * SVGViewElement.viewBox (read-only)
          * : An SVGAnimatedRect corresponding to the viewBox attribute of the given view element.
        * SVGViewElement.preserveAspectRatio (read-only)
          * : An SVGAnimatedPreserveAspectRatio corresponding to the preserveAspectRatio attribute of the given view element.

       INSTANCE METHODS

       _This interface doesn't implement any specific methods, but inherits methods from its parent interface, SVGElement._
