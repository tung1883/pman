       NAME

       MediaStreamTrack: muted property - The muted read-only property of the

       MEDIASTREAMTRACK: MUTED PROPERTY

       The muted read-only property of the MediaStreamTrack interface returns a boolean value indicating whether or not the track is currently unable to provide media output.

       > To implement a way for users to mute and unmute a track, use the
       > enabled property. When a track is disabled
       > by setting enabled to false, it generates only empty frames
       > (audio frames in which every sample is 0, or video frames in which every pixel is
       > black).

       VALUE

       A boolean which is true if the track is currently muted, or false if the track is currently unmuted.

       > When possible, avoid polling muted to monitor the track's muting status.
       > Instead, add event listeners for the mute and unmute events.

       EXAMPLES

       This example counts the number of tracks in an array of MediaStreamTrack objects which are currently muted.

         let mutedCount = 0;

         trackList.forEach((track) => {
           if (track.muted) {
             mutedCount += 1;
           }
         });
