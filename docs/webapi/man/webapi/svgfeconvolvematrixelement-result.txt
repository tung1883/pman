       NAME

       SVGFEConvolveMatrixElement: result property - The result read-only property of the SVGFEConvolveMatrixElement interface describes the assigned name of an SVG filter primitive as a SVGAni

       SVGFECONVOLVEMATRIXELEMENT: RESULT PROPERTY

       The result read-only property of the SVGFEConvolveMatrixElement interface describes the assigned name of an SVG filter primitive as a SVGAnimatedString.

       It reflects the feConvolveMatrix element's result attribute. The filter applies a matrix convolution effect, combining pixels in the input image with neighboring pixels to produce a convolution effect such as blurring, edge detection, sharpening, embossing or beveling.

       The attribute value is a custom-ident. If supplied, then graphics that result from processing this filter primitive can be referenced by an in attribute on a subsequent filter primitive within the same filter element.

       If no result attribute is defined, the filter's result.baseVal and result.animVal are empty strings, and the output of the filter will only be available for re-use as the implicit input into the next filter primitive if that filter primitive provides no value for its in attribute.

       VALUE

       An SVGAnimatedString.

       EXAMPLE

         const feConvolveMatrixElement = document.querySelector("feConvolveMatrix");
         const filterName = feConvolveMatrixElement.result;
         console.log(filterName.baseVal); // the filter's assigned name
