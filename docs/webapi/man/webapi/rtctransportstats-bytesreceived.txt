       NAME

       RTCTransportStats: bytesReceived property - The bytesReceived property of the RTCTransportStats dictionary indicates the total number of payload bytes received on this transport.

       RTCTRANSPORTSTATS: BYTESRECEIVED PROPERTY

       The bytesReceived property of the RTCTransportStats dictionary indicates the total number of payload bytes received on this transport.

       Only data bytes are counted; overhead such as padding, headers, and so on are not included in this count.

       VALUE

       A non-negative integer indicating the number of received payload bytes.
