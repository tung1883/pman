       NAME

       HTMLObjectElement: useMap property - The useMap property of the

       HTMLOBJECTELEMENT: USEMAP PROPERTY

       The useMap property of the HTMLObjectElement interface returns a string that reflects the usemap HTML attribute, specifying a element to use.

       VALUE

       A string.
