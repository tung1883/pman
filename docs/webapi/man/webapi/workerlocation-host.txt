WEBAPI.WORKERLOCATION-HOST(1)    Sandbox manual    WEBAPI.WORKERLOCATION-HOST(1)

       NAME

       WorkerLocation: host property - worker

       WORKERLOCATION: HOST PROPERTY

       worker

       The host property of a WorkerLocation object returns the host part of the worker's location.

       VALUE

       A string.

       EXAMPLES

         // In a Web worker, on the page http://localhost:8080/
         const result = location.host; // Returns 'localhost:8080'
