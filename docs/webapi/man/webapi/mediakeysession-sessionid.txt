WEBAPI.MEDIAKEYSESSION-SESSIONID(1) Sandbox manual WEBAPI.MEDIAKEYSESSION-SESSIONID(1)

       NAME

       MediaKeySession: sessionId property - The sessionId read-only property of the MediaKeySession interface contains a unique string generated by the content decryption module (CDM) 

       MEDIAKEYSESSION: SESSIONID PROPERTY

       The sessionId read-only property of the MediaKeySession interface contains a unique string generated by the content decryption module (CDM) for the current media object and its associated keys or licenses.

       VALUE

       A string.
