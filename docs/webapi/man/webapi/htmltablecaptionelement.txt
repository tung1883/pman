       HTMLTABLECAPTIONELEMENT

       The HTMLTableCaptionElement interface provides special properties (beyond the regular HTMLElement interface it also has available to it by inheritance) for manipulating table elements.

       INSTANCE PROPERTIES

       _Inherits properties from its parent, HTMLElement._

        * HTMLTableCaptionElement.align (deprecated)
          * : A string which represents an enumerated attribute indicating alignment of the caption with respect to the table.

       INSTANCE METHODS

       _No specific method; inherits methods from its parent, HTMLElement_.
