       NAME

       FormData: delete() method - The delete() method of the FormData interface deletes a key and its value(s) from a FormData object.

       FORMDATA: DELETE() METHOD

       The delete() method of the FormData interface deletes a key and its value(s) from a FormData object.

       SYNTAX

         delete(name)

       PARAMETERS

        * name
          * : The name of the key you want to delete.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       You can delete a key and its values using delete():

         formData.delete("username");
