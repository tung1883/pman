       NAME

       CSSSkewY: CSSSkewY() constructor - The CSSSkewY() constructor creates a new CSSSkewY object that represents the skewY() value of the individual transform property in CSS.

       CSSSKEWY: CSSSKEWY() CONSTRUCTOR

       The CSSSkewY() constructor creates a new CSSSkewY object that represents the skewY() value of the individual transform property in CSS.

       SYNTAX

         new CSSSkewY(ay)

       PARAMETERS

        * ay
          * : A value for the ay angle of the CSSSkewY object to be constructed.
       This must be a CSSNumericValue.
