       NAME

       NavigationDestination: sameDocument property - The sameDocument read-only property of the

       NAVIGATIONDESTINATION: SAMEDOCUMENT PROPERTY

       The sameDocument read-only property of the NavigationDestination interface returns true if the navigation is to the same document as the current Document value, or false otherwise.

       This is useful for checking whether the navigation will be same-document or cross-document.

       VALUE

       A boolean.

       EXAMPLES

         navigation.addEventListener("navigate", (event) => {
           console.log(event.destination.sameDocument);
         });
