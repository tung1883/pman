       NAME

       NotRestoredReasons: children property - The children read-only property of the

       NOTRESTOREDREASONS: CHILDREN PROPERTY

       The children read-only property of the NotRestoredReasons interface returns an array of NotRestoredReasons objects, one for each child embedded in the current document, which may contain reasons why the top-level frame was blocked relating to the child frames.

       Each object has the same structure as the parent object — this way, any number of levels of embedded s can be represented inside the object recursively.

       VALUE

       An array of NotRestoredReasons objects.

       If the frame has no children, the array will be empty; if the document is in a cross-origin , children will return null.
