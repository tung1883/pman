       SVGFECOLORMATRIXELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFEColorMatrixElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feColorMatrix element's width filter primitive attribute. The filter applies a matrix transformation on the RGB color and alpha values. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feColorMatrix = document.querySelector("feColorMatrix");
         const horizontalSize = feColorMatrix.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
