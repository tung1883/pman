       NAME

       PerformanceTiming: domContentLoadedEventEnd property - > [!WARNING]

       PERFORMANCETIMING: DOMCONTENTLOADEDEVENTEND PROPERTY

       > This interface of this property is deprecated in the Navigation Timing Level 2 specification. Please use the PerformanceNavigationTiming
       > interface instead.
       The legacy PerformanceTiming.domContentLoadedEventEnd read-only property returns an unsigned long long representing the moment, in milliseconds since the UNIX epoch, right after all the scripts that need to be executed as soon as possible, in order or not, has been executed.

       VALUE

       An unsigned long long.
