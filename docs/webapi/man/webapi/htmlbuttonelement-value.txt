       HTMLBUTTONELEMENT: VALUE PROPERTY

       The value property of the HTMLButtonElement interface represents the value of the element as a string, or the empty string if no value is set. It reflects the element's value attribute.

       VALUE

       A string containing the value of the element.

       EXAMPLES

         const buttonElement = document.getElementById("given-name");
         console.log(`value: ${buttonElement.value}`);
