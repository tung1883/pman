       NAME

       DocumentType: remove() method - The DocumentType.remove() method removes a document's doctype.

       DOCUMENTTYPE: REMOVE() METHOD

       The DocumentType.remove() method removes a document's doctype. If it is already detached from the document, calling remove() does nothing.

       SYNTAX

         remove()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       USING REMOVE()

         document.doctype; // "<!doctype html>'
         document.doctype.remove();
         document.doctype; // null
