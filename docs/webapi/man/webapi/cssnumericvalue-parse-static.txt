       NAME

       CSSNumericValue: parse() static method - The parse() static method of the CSSNumericValue interface converts a value string into an object whose members are value and the units.

       CSSNUMERICVALUE: PARSE() STATIC METHOD

       The parse() static method of the CSSNumericValue interface converts a value string into an object whose members are value and the units.

       > This method cannot be called in Worker or Worklet contexts — parsing CSS text is restricted to the main thread.
       > All other methods in the CSSNumericValue interface are available in workers and worklets.

       SYNTAX

         CSSNumericValue.parse(cssText)

       PARAMETERS

        * cssText
          * : a string containing numeric and unit parts.

       RETURN VALUE

       A CSSNumericValue.

       EXCEPTIONS

        * SyntaxError DOMException
          * : TBD

       EXAMPLES

       BASIC USAGE

       The following code returns a CSSUnitValue object with a unit property equal to "px" and a value property equal to 42.

         let numValue = CSSNumericValue.parse("42.0px");
