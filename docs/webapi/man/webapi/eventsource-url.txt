       NAME

       EventSource: url property - The url read-only property of the

       EVENTSOURCE: URL PROPERTY

       The url read-only property of the EventSource interface returns a string representing the URL of the source.

       VALUE

       A string representing the URL of the source.

       EXAMPLES

         const evtSource = new EventSource("sse.php");
         console.log(evtSource.url);

       > You can find a full example on GitHub — see Simple SSE demo using PHP.
