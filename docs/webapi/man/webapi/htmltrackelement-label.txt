       HTMLTRACKELEMENT: LABEL PROPERTY

       The label property of the HTMLTrackElement represents the user-readable title displayed when listing subtitle, caption, and audio descriptions for a track. It reflects the element's label attribute.

       VALUE

       A string.

       EXAMPLE

         const trackElement = document.getElementById("exampleTrack");
         console.log(`Track's label: ${trackElement.label}`);
         trackElement.label = "Updated label";
