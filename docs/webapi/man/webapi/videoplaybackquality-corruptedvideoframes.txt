WEBAPI.VIDEOPLAYBACKQUALITY-CORRUPTEDVIDEOFRAMES(1) Sandbox manual WEBAPI.VIDEOPLAYBACKQUALITY-CORRUPTEDVIDEOFRAMES(1)

       NAME

       VideoPlaybackQuality: corruptedVideoFrames property - The VideoPlaybackQuality interface's read-only

       VIDEOPLAYBACKQUALITY: CORRUPTEDVIDEOFRAMES PROPERTY

       The VideoPlaybackQuality interface's read-only corruptedVideoFrames property the number of corrupted video frames that have been received since the element was last loaded or reloaded.

       VALUE

       The number of corrupted video frames that have been received since the element was last loaded or reloaded.

       It is up to the user agent to determine whether or not to display a corrupted video frame. If a corrupted frame is dropped, then both corruptedVideoFrames and droppedVideoFrames are incremented.

       EXAMPLES

       This example determines the percentage of frames which have been corrupted, and if the value is greater than 5%, calls a function called downgradeVideo() that would be implemented to switch to a different video that might tax the network less.

         const videoElem = document.getElementById("my_vid");
         const quality = videoElem.getVideoPlaybackQuality();

         if (quality.corruptedVideoFrames / quality.totalVideoFrames > 0.05) {
           downgradeVideo(videoElem);
         }
