       NAME

       WebSocketStream: url property - The url read-only property of the

       WEBSOCKETSTREAM: URL PROPERTY

       {{non-standard_header}}

       The url read-only property of the WebSocketStream interface returns the URL of the WebSocket server that the WebSocketStream instance was created with.

       VALUE

       A string.

       EXAMPLES

         const wss = new WebSocketStream("wss://example.com/wss");

         // Logs "example.com/wss" to the console
         console.log(wss.url);

       SPECIFICATIONS

       Not currently a part of any specification. See https://github.com/whatwg/websockets/pull/48 for standardization progress.
