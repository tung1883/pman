       NAME

       HTMLSelectElement: multiple property - The multiple property of the HTMLSelectElement interface specifies that the user may select more than one option from the list of options. I

       HTMLSELECTELEMENT: MULTIPLE PROPERTY

       The multiple property of the HTMLSelectElement interface specifies that the user may select more than one option from the list of options. It reflects the element's multiple attribute.

       VALUE

       A boolean.

       EXAMPLES

         const selectElement = document.getElementById("comment");
         console.log(selectElement.multiple);
