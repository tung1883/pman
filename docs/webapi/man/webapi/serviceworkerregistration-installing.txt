       NAME

       ServiceWorkerRegistration: installing property - The installing read-only property of the

       SERVICEWORKERREGISTRATION: INSTALLING PROPERTY

       The installing read-only property of the ServiceWorkerRegistration interface returns a service worker whose ServiceWorker.state is installing. This property is initially set to null.

       VALUE

       A ServiceWorker object, if it is currently in an installing state.
