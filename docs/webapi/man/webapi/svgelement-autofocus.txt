       SVGELEMENT: AUTOFOCUS PROPERTY

       The autofocus property of the SVGElement interface contains a boolean value reflecting the autofocus HTML global attribute. It indicates whether the SVG element should be focused when the page loads or when the element becomes shown if the SVG element is inside a or a popover.

       VALUE

       A boolean value.
