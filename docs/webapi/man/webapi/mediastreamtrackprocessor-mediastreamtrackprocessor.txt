       MediaStreamTrackProcessor: MediaStreamTrackProcessor() constructor - The MediaStreamTrackProcessor() constructor creates a new MediaStreamTrackProcessor object which consumes a video MediaStreamTrack object's 

       MEDIASTREAMTRACKPROCESSOR: MEDIASTREAMTRACKPROCESSOR() CONSTRUCTOR

       The MediaStreamTrackProcessor() constructor creates a new MediaStreamTrackProcessor object which consumes a video MediaStreamTrack object's source and generates a stream of VideoFrames.

       SYNTAX

         new MediaStreamTrackProcessor(options)

       PARAMETERS

        * options
          * : An object with the following properties:
            * track
              * : A MediaStreamTrack.
            * maxBufferSize (optional)
              * : An integer specifying the maximum number of media frames to be buffered.

       EXAMPLES

       In the following example a new MediaStreamTrackProcessor is created.

         const trackProcessor = new MediaStreamTrackProcessor({ track: videoTrack });
