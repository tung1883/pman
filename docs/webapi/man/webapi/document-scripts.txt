       NAME

       Document: scripts property - The scripts property of the Document

       DOCUMENT: SCRIPTS PROPERTY

       The scripts property of the Document interface returns a list of the elements in the document. The returned object is an HTMLCollection.

       VALUE

       An HTMLCollection. You can use this just like an array to get all the elements in the list.

       EXAMPLES

       This example looks to see if the page has any elements.

         let scripts = document.scripts;

         if (scripts.length) {
           alert("This page has scripts!");
         }
