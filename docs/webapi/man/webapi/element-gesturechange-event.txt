       NAME

       Element: gesturechange event - The gesturechange event is fired when digits move during a touch gesture.

       ELEMENT: GESTURECHANGE EVENT

       {{Non-standard_header}}

       The gesturechange event is fired when digits move during a touch gesture.

       It is a proprietary event specific to WebKit.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("gesturechange", (event) => { })

         ongesturechange = (event) => { }

       EVENT TYPE

       A GestureEvent. Inherits from Event.

       GestureEvent

       SPECIFICATIONS

       Not part of any specification.
