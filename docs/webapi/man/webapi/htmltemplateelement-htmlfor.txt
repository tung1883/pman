       NAME

       HTMLTemplateElement: htmlFor property - The htmlFor property of the HTMLTemplateElement interface is the ID of the Processing Instruction marker to replace with the contents of the

       HTMLTEMPLATEELEMENT: HTMLFOR PROPERTY

       The htmlFor property of the HTMLTemplateElement interface is the ID of the Processing Instruction marker to replace with the contents of the associated element. It reflects the value of, and is used to set and get the for content attribute.

       VALUE

       A string containing the ID of the Processing Instruction marker to replace with the contents of this element.

       DESCRIPTION

       The for attribute of a element is used for template out-of-order patching using <?marker> and <?start>/<?end> processing instruction markers. Those markers are replaced with the contents of the element when it is parsed and processed.

       The htmlFor attribute provides JavaScript access to the attribute value. htmlFor is used instead of for to avoid clashing with the JavaScript for reserved word (this is no longer strictly necessary, so may change in the future).

       EXAMPLES

       BASIC USAGE

         <template for="my-identifier"> Lorem Ipsum... </template>

         console.log(document.querySelector("template").htmlFor);
         // my-identifier
