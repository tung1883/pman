WEBAPI.WORKERLOCATION-SEARCH(1)  Sandbox manual  WEBAPI.WORKERLOCATION-SEARCH(1)

       NAME

       WorkerLocation: search property - worker

       WORKERLOCATION: SEARCH PROPERTY

       worker

       The search property of a WorkerLocation object returns the search part of the worker's location.

       VALUE

       A string.

       EXAMPLES

         // In a Web worker, on the page https://developer.mozilla.org/en-US/docs/Web?t=67
         const result = location.search; // Returns:'?t=67'
