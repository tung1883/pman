       NAME

       HTMLTrackElement: src property - The src property of the HTMLTrackElement interface reflects the value of

       HTMLTRACKELEMENT: SRC PROPERTY

       The src property of the HTMLTrackElement interface reflects the value of the element's src attribute, which indicates the URL of the text track's data.

       VALUE

       A string containing the URL of the text track data.

       EXAMPLE

         const trackElement = document.getElementById("exampleTrack");
         console.log(`Track's URL: ${trackElement.src}`);
         trackElement.src = "newTrack.vtt";
