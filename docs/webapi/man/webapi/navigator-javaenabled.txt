WEBAPI.NAVIGATOR-JAVAENABLED(1)  Sandbox manual  WEBAPI.NAVIGATOR-JAVAENABLED(1)

       NAME

       Navigator: javaEnabled() method - This method always returns false.

       NAVIGATOR: JAVAENABLED() METHOD

       This method always returns false.

       SYNTAX

         javaEnabled()

       PARAMETERS

       None.

       RETURN VALUE

       The boolean value false.

       EXAMPLES

         if (window.navigator.javaEnabled()) {
           // code will never be executed; the condition is always false
         }
