       NAME

       Window: cancelIdleCallback() method - The window.cancelIdleCallback() method cancels a callback

       WINDOW: CANCELIDLECALLBACK() METHOD

       The window.cancelIdleCallback() method cancels a callback previously scheduled with window.requestIdleCallback().

       SYNTAX

         cancelIdleCallback(handle)

       PARAMETERS

        * handle
          * : The ID value returned by window.requestIdleCallback() when the
       callback was established.

       RETURN VALUE

       None (undefined).

       See our complete example in the article Cooperative Scheduling of Background Tasks API.
