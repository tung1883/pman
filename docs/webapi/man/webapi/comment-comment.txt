       NAME

       Comment: Comment() constructor - The Comment() constructor returns a newly created

       COMMENT: COMMENT() CONSTRUCTOR

       The Comment() constructor returns a newly created Comment object with the optional string given in parameter as its textual content.

       SYNTAX

         new Comment()
         new Comment(content)

       PARAMETERS

        * content (optional)
          * : A string representing the textual content of the comment.

       RETURN VALUE

       A new Comment containing content, or the empty string if no parameter was given.

       EXAMPLE

         const comment = new Comment("Test");

       SPECIFICATIONS

       BROWSER COMPATIBILITY
