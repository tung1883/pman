       NAME

       Range: selectNode() method - The Range.selectNode() method sets the

       RANGE: SELECTNODE() METHOD

       The Range.selectNode() method sets the Range to contain the Node and its contents. The parent Node of the start and end of the Range will be the same as the parent of the _referenceNode_.

       SYNTAX

         selectNode(referenceNode)

       PARAMETERS

        * referenceNode
          * : The Node to select within a Range.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         let range = document.createRange();
         let referenceNode = document.getElementsByTagName("div").item(0);

         range.selectNode(referenceNode);
