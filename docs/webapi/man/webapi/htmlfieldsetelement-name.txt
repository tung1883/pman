       NAME

       HTMLFieldSetElement: name property - The name property of the HTMLFieldSetElement interface indicates the name of the <fieldset> element. It reflects the element's name attribut

       HTMLFIELDSETELEMENT: NAME PROPERTY

       The name property of the HTMLFieldSetElement interface indicates the name of the element. It reflects the element's name attribute.

       VALUE

       A string representing the element's name.

       EXAMPLE

         const fs = document.querySelector("fieldset");
         console.log(`Element's name: ${fs.name}`);
         fs.name = "billing"; // sets or updates the element's name
