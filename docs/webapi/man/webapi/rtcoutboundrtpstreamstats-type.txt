       NAME

       RTCOutboundRtpStreamStats: type property - The type property of the RTCOutboundRtpStreamStats dictionary is a string with the value "outbound-rtp".

       RTCOUTBOUNDRTPSTREAMSTATS: TYPE PROPERTY

       The type property of the RTCOutboundRtpStreamStats dictionary is a string with the value "outbound-rtp".

       Different statistics are obtained by iterating the RTCStatsReport object returned by a call to RTCPeerConnection.getStats(). The type indicates the set of statistics available through the object in a particular iteration step. A value of "outbound-rtp" indicates that the statistics available in the current step are those defined in RTCOutboundRtpStreamStats.

       VALUE

       A string with the value "outbound-rtpp".
