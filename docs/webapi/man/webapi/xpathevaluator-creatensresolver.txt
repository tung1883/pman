       XPathEvaluator: createNSResolver() method - The createNSResolver() method of the XPathEvaluator interface used to create a custom XPathNSResolver object. It now returns the input as-is

       XPATHEVALUATOR: CREATENSRESOLVER() METHOD

       The createNSResolver() method of the XPathEvaluator interface used to create a custom XPathNSResolver object. It now returns the input as-is and is only kept for compatibility reasons.

       SYNTAX

         createNSResolver(nodeResolver)

       PARAMETERS

        * nodeResolver
          * : A Node.

       RETURN VALUE

       nodeResolver itself.
