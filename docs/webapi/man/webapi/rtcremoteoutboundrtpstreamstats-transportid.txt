       NAME

       RTCRemoteOutboundRtpStreamStats: transportId property - The transportId property of the RTCRemoteOutboundRtpStreamStats dictionary is a string that uniquely identifies the associated RTCTransportS

       RTCREMOTEOUTBOUNDRTPSTREAMSTATS: TRANSPORTID PROPERTY

       The transportId property of the RTCRemoteOutboundRtpStreamStats dictionary is a string that uniquely identifies the associated RTCTransportStats statistics object for this RTP stream's underlying transport.

       RTCRemoteOutboundRtpStreamStats and RTCTransportStats objects are correlated by iterating the RTCStatsReport to find the statistics objects where RTCRemoteOutboundRtpStreamStats.transportId is equal to RTCTransportStats.id.

       VALUE

       A string that contains the id of the object that was inspected to produce the RTCTransportStats object associated with this RTP stream.
