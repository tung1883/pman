       HTMLTEXTAREAELEMENT: WRAP PROPERTY

       The wrap property of the HTMLTextAreaElement interface indicates how the control should wrap the value for form submission. It reflects the element's wrap attribute. Note that the "hard" value only has an effect when the cols attribute is also set.

       VALUE

       See wrap for the possible values. Defaults to "soft".

       EXAMPLES

         const textareaElement = document.getElementById("comment");
         const oldWrap = textArea.wrap;
         textArea.wrap = "hard"; // Add line breaks (CR+LF) during form submission
