       NAME

       HTMLTableRowElement: bgColor property - The HTMLTableRowElement.bgColor property is used to set the background color of a row or retrieve the value of the obsolete bgColor attribut

       HTMLTABLEROWELEMENT: BGCOLOR PROPERTY

       The HTMLTableRowElement.bgColor property is used to set the background color of a row or retrieve the value of the obsolete bgColor attribute, if present.

       > This property is deprecated and CSS should be used to set the background color. Use the background-color property instead.

       VALUE

       One of the following value types can be used:

        * a named color, like red or blue
        * a hex code, like #0000dd
       > The values accepted here are a subset of the CSS color values. You can reuse HTML color values in CSS, but not in the other direction: the unknown colors would appear differently than expected.

       EXAMPLES

       Use CSS background-color instead. An example is available on the background-color page.
