       NAME

       HTMLLinkElement: href property - The href property of the HTMLLinkElement interface contains a string that is the URL associated with the link.

       HTMLLINKELEMENT: HREF PROPERTY

       The href property of the HTMLLinkElement interface contains a string that is the URL associated with the link.

       It reflects the href attribute of the element. If the element does not have an href attribute, then this property's value is the empty string ("").

       > Every element must contain either one or both of the href or imagesrcset attributes. This means, for each valid , either this property or imageSrcset will not be empty.

       VALUE

       A string that contains a URL, or the empty string ("") if there is no href element.

       EXAMPLES

         <link rel="stylesheet" href="example.css" />

         const link = document.getElementsByTag("link")[0];
         console.log(link.href); // 'example.css'
