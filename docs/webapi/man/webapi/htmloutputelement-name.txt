       NAME

       HTMLOutputElement: name property - The name property of the HTMLOutputElement interface indicates the name of the <output> element. It reflects the element's name attribute.

       HTMLOUTPUTELEMENT: NAME PROPERTY

       The name property of the HTMLOutputElement interface indicates the name of the element. It reflects the element's name attribute.

       VALUE

       A string representing the element's name.

       EXAMPLE

         const outputElement = document.querySelector("#log");
         console.log(`Element's name: ${outputElement.name}`);
         outputElement.name = "sum"; // sets or updates the element's name
