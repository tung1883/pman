WEBAPI.VIEWTRANSITION-TRANSITIONROOT(1) Sandbox manual WEBAPI.VIEWTRANSITION-TRANSITIONROOT(1)

       NAME

       ViewTransition: transitionRoot property - The transitionRoot read-only property of the ViewTransition interface is a reference to the root Element of the view transition scope.

       VIEWTRANSITION: TRANSITIONROOT PROPERTY

       The transitionRoot read-only property of the ViewTransition interface is a reference to the root Element of the view transition scope.

       VALUE

       An Element.

        * For document-scoped view transitions, transitionRoot is a reference to the Document.documentElement property, which for standard web documents is a reference to the element.
        * For element-scoped view transitions, transitionRoot is a reference to the Element that startViewTransition() was called on to create the view transition.

       EXAMPLES

       BASIC USAGE

       This snippet shows how to use transitionRoot to retrieve a reference to the element the view transition was created on.

         const myElement = document.querySelector(".my-element");

         // ...

         function handleVT() {
           const vt = myElement.startViewTransition(() => {
             updateDOMSomehow();
           });

           // ...

           // Returns reference to myElement
           vt.transitionRoot;
         }
