WEBAPI.SVGANGLE-VALUE(1)         Sandbox manual         WEBAPI.SVGANGLE-VALUE(1)

       NAME

       SVGAngle: value property - The value property of the SVGAngle interface represents the floating point value of the <angle> in degrees.

       SVGANGLE: VALUE PROPERTY

       The value property of the SVGAngle interface represents the floating point value of the in degrees.

       Setting this attribute will cause valueInSpecifiedUnits and valueAsString to be updated automatically to reflect this setting.

       VALUE

       A number; the angle value in degrees.

       EXAMPLES

         // Get an SVGAngle object
         const svg = document.querySelector("svg");
         const angle = svg.createSVGAngle();

         // Set the value
         angle.value = 45;
         console.log(angle.value); // Output: 45

         // Reflecting the value
         angle.value = 90;
         console.log(angle.value); // Output: 90
