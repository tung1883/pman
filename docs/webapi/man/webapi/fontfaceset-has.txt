       NAME

       FontFaceSet: has() method - The has() method of the FontFaceSet interface returns a Boolean asserting whether an element is present with the given value.

       FONTFACESET: HAS() METHOD

       The has() method of the FontFaceSet interface returns a Boolean asserting whether an element is present with the given value.

       SYNTAX

         has(value)

       PARAMETERS

        * value
          * : The value to test for in the FontFaceSet object.

       RETURN VALUE

       A Boolean, true if value exists in the FontFaceSet.
