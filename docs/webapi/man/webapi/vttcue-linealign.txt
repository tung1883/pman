WEBAPI.VTTCUE-LINEALIGN(1)       Sandbox manual       WEBAPI.VTTCUE-LINEALIGN(1)

       NAME

       VTTCue: lineAlign property - The lineAlign property of the VTTCue interface represents the alignment of this VTT cue.

       VTTCUE: LINEALIGN PROPERTY

       The lineAlign property of the VTTCue interface represents the alignment of this VTT cue.

       VALUE

       A string containing one of the following values:

        * "start"
          * : Start alignment.
        * "center"
          * : Center alignment.
        * "end"
          * : End alignment.

       EXAMPLES

       In the following example a new VTTCue is created, then the value of lineAlign is set to "center". The value is then printed to the console.

         let video = document.querySelector("video");
         let track = video.addTextTrack("captions", "Captions", "en");
         track.mode = "showing";

         let cue = new VTTCue(0, 0.9, "Hildy!");
         cue.lineAlign = "center";
         console.log(cue.lineAlign);

         track.addCue(cue);
