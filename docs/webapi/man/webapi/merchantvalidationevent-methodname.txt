       NAME

       MerchantValidationEvent: methodName property - The MerchantValidationEvent property

       MERCHANTVALIDATIONEVENT: METHODNAME PROPERTY

       {{non-standard_header}}

       The MerchantValidationEvent property methodName is a read-only value which returns a string indicating the payment method identifier which represents the payment handler that requires merchant validation.

       VALUE

       A read-only string which uniquely identifies the payment handler which is requesting merchant validation. See Merchant validation for more information on the process.
