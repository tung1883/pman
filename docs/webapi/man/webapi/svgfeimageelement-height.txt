       SVGFEIMAGEELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFEImageElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the height attribute of the feImage element, which fetches image data from an external source and provides the pixel data as output. The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feImage = document.querySelector("feImage");
         const verticalSize = feImage.height;
         console.log(verticalSize.baseVal.value); // the `height` value
