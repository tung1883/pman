WEBAPI.SVGLENGTH-VALUE(1)        Sandbox manual        WEBAPI.SVGLENGTH-VALUE(1)

       NAME

       SVGLength: value property - The value property of the SVGLength interface represents the floating point value of the \<length> in user units.

       SVGLENGTH: VALUE PROPERTY

       The value property of the SVGLength interface represents the floating point value of the \ in user units.

       Setting this attribute will cause SVGLength.valueInSpecifiedUnits and SVGLength.valueAsString to be updated automatically to reflect this setting.

       VALUE

       The length value in user units as a float.

       EXAMPLES

         // Get an SVGLength object
         const svg = document.querySelector("svg");
         const length = svg.createSVGLength();

         // Set the value
         length.value = 10;
         console.log(length.value); // Output: 10

         // Reflecting the value
         length.value = 20;
         console.log(length.value); // Output: 20
