       NAME

       ContactAddress: postalCode property - The postalCode read-only property of the ContactAddress interface returns a string containing a code used by a jurisdiction for mail routing

       CONTACTADDRESS: POSTALCODE PROPERTY

       The postalCode read-only property of the ContactAddress interface returns a string containing a code used by a jurisdiction for mail routing, for example, the ZIP Code in the United States or the Postal Index Number (PIN code) in India.

       VALUE

       A string which contains the postal code portion of the address. A postal code is a string (either numeric or alphanumeric) which is used by a postal service to optimize mail routing and delivery.

       Various countries use different terms for this. In most of the world, it's known as the "post code" or "postal code". In the United States, the ZIP code is used. India uses PIN codes.
