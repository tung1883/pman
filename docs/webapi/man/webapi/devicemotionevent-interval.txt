       NAME

       DeviceMotionEvent: interval property - The interval read-only property of the DeviceMotionEvent interface returns the interval, in milliseconds, at which data is obtained from the

       DEVICEMOTIONEVENT: INTERVAL PROPERTY

       The interval read-only property of the DeviceMotionEvent interface returns the interval, in milliseconds, at which data is obtained from the underlying hardware. You can use this to determine the granularity of motion events.

       VALUE

       A number representing the interval of time, in milliseconds.
