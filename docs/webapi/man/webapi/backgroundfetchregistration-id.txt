WEBAPI.BACKGROUNDFETCHREGISTRATION-ID(1) Sandbox manual WEBAPI.BACKGROUNDFETCHREGISTRATION-ID(1)

       NAME

       BackgroundFetchRegistration: id property - The id read-only property of the BackgroundFetchRegistration interface returns a copy of the background fetch's ID.

       BACKGROUNDFETCHREGISTRATION: ID PROPERTY

       The id read-only property of the BackgroundFetchRegistration interface returns a copy of the background fetch's ID.

       VALUE

       A string.

       EXAMPLES

       Logging the this part to the console returns the identifier set when registering the fetch. In this case, "my-fetch".

         console.log(bgFetch.id); // "my-fetch"
