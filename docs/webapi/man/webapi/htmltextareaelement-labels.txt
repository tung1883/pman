       NAME

       HTMLTextAreaElement: labels property - The HTMLTextAreaElement.labels read-only property returns

       HTMLTEXTAREAELEMENT: LABELS PROPERTY

       The HTMLTextAreaElement.labels read-only property returns a NodeList of the elements associated with the element.

       VALUE

       A NodeList containing the elements associated with the element.

       EXAMPLES

       HTML

         <label id="label1" for="test">Label 1</label>
         <textarea id="test">Some text</textarea>
         <label id="label2" for="test">Label 2</label>

       JAVASCRIPT

         const textArea = document.getElementById("test");
         for (const label of textArea.labels) {
           console.log(label.textContent); // "Label 1" and "Label 2"
         }
