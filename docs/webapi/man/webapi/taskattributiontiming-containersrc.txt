       TaskAttributionTiming: containerSrc property - The containerSrc read-only property of the TaskAttributionTiming interface returns the container's src

       TASKATTRIBUTIONTIMING: CONTAINERSRC PROPERTY

       The containerSrc read-only property of the TaskAttributionTiming interface returns the container's src attribute. A container is the iframe, embed or object etc. that is being implicated, on the whole, for a long task.

       VALUE

       A string containing the container's src attribute (e.g., ).
