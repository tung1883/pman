       NAME

       HTMLButtonElement: formNoValidate property - The formNoValidate property of the HTMLButtonElement interface is a boolean value indicating if the <form> will bypass constraint validation

       HTMLBUTTONELEMENT: FORMNOVALIDATE PROPERTY

       The formNoValidate property of the HTMLButtonElement interface is a boolean value indicating if the will bypass constraint validation when submitted via the . It reflects the element's formnovalidate attribute.

       Its value overrides the noValidate property of the HTMLFormElement interface if the form is submitted via the button. This property can be retrieved or set.

       VALUE

       A boolean.

       EXAMPLES

         const buttonElement = document.getElementById("myButton");
         console.log(buttonElement.formNoValidate);
