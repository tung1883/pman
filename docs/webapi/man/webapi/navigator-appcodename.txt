       NAME

       Navigator: appCodeName property - The value of the Navigator.appCodeName property is

       NAVIGATOR: APPCODENAME PROPERTY

       The value of the Navigator.appCodeName property is always "Mozilla", in any browser. This property is kept only for compatibility purposes.

       > Do not rely on this property to return a real
       > product name. All browsers return "Mozilla" as the value of this property.

       VALUE

       The string "Mozilla".
