       NAME

       HTMLAreaElement: interestForElement property - The interestForElement property of the HTMLAreaElement interface gets or sets the target element of an interest invoker, in cases where the 

       HTMLAREAELEMENT: INTERESTFORELEMENT PROPERTY

       {{non-standard_header}}

       The interestForElement property of the HTMLAreaElement interface gets or sets the target element of an interest invoker, in cases where the associated element is specified as an interest invoker.

       See Creating an interest invoker for more details.

       VALUE

       An Element object instance, or null if the associated element does not have a target element set.

       EXAMPLES

       BASIC INTERESTFORELEMENT USAGE

       In this example, we use an element's interestForElement property to set its target element and then retrieve the target element's tagName. The tagName is then printed in the element's text content.

       HTML

       We include an element and a element. We turn the element into a popover by setting a popover attribute on it.

         <map name="example-map" id="example-map">
           <area href="#" shape="default" alt="Example area" />
         </map>
         <div id="mypopover" popover>I am a <code>&lt;div&gt;</code> element.</div>

         map {
           width: 200px;
           height: 100px;
           background-color: pink;
           padding: 5px;
         }

       JAVASCRIPT

       We get references to the and elements in script, then declare an interest invoker-target relationship between the and the by setting the element's interestForElement property equal to a reference to the . We then set the element's text content equal to a string containing the target element's tagName, retrieved via invoker.interestForElement.tagName.

         const invoker = document.querySelector("area");
         const popover = document.querySelector("div");

         invoker.interestForElement = popover;

         invoker.textContent = `My target is a ${invoker.interestForElement.tagName} element`;
