WEBAPI.CSSTRANSFORMVALUE-LENGTH(1) Sandbox manual WEBAPI.CSSTRANSFORMVALUE-LENGTH(1)

       NAME

       CSSTransformValue: length property - The length read-only property of the CSSTransformValue interface returns the number of items in the object.

       CSSTRANSFORMVALUE: LENGTH PROPERTY

       The length read-only property of the CSSTransformValue interface returns the number of items in the object.

       VALUE

       An integer.

       EXAMPLES

       BASIC USAGE

         const transform = new CSSTransformValue([
           new CSSTranslate(CSS.px(10), CSS.px(20)),
           new CSSScale(2, 3),
         ]);

         console.log(transform.length); // 2
