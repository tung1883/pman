       NAME

       HTMLTableElement: border property - The HTMLTableElement.border property represents the

       HTMLTABLEELEMENT: BORDER PROPERTY

       The HTMLTableElement.border property represents the border width of the element.

       VALUE

       A string representing the width of the border in pixels.

       EXAMPLES

         // Set the width of a table border to 2 pixels
         const t = document.getElementById("TableA");
         t.border = "2";
