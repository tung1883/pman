       NAME

       PasswordCredential: password property - The password read-only property

       PASSWORDCREDENTIAL: PASSWORD PROPERTY

       The password read-only property of the PasswordCredential interface returns a string containing the password of the credential.

       VALUE

       A string containing a password.
