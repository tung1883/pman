WEBAPI.EXTENDABLEMESSAGEEVENT-DATA(1) Sandbox manual WEBAPI.EXTENDABLEMESSAGEEVENT-DATA(1)

       NAME

       ExtendableMessageEvent: data property - service

       EXTENDABLEMESSAGEEVENT: DATA PROPERTY

       service

       The data read-only property of the ExtendableMessageEvent interface returns the event's data. It can be any data type.

       VALUE

       Any data type.

       EXAMPLES

       When the following code is used inside a service worker to respond to a push messages by sending the data received via PushMessageData to the main context via a channel message, the event object of onmessage will be an ExtendableMessageEvent.

         let port;

         self.addEventListener("push", (e) => {
           const obj = e.data.json();

           if (obj.action === "subscribe" || obj.action === "unsubscribe") {
             port.postMessage(obj);
           } else if (obj.action === "init" || obj.action === "chatMsg") {
             port.postMessage(obj);
           }
         });

         self.onmessage = (e) => {
           console.log(e.data);
           port = e.ports[0];
         };
