       NAME

       Document: createRange() method - The Document.createRange() method returns a new

       DOCUMENT: CREATERANGE() METHOD

       The Document.createRange() method returns a new Range object whose start and end are offset 0 of the Document object on which it was called.

       SYNTAX

         createRange()

       PARAMETERS

       None.

       RETURN VALUE

       The created Range object.

       EXAMPLES

         const range = document.createRange();

         range.setStart(startNode, startOffset);
         range.setEnd(endNode, endOffset);

       NOTES

       Once a Range is created, you need to set its boundary points before you can make use of most of its methods.
