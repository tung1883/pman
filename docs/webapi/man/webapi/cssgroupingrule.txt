       NAME

       CSSGroupingRule - The CSSGroupingRule interface of the CSS Object Model represents any CSS at-rule that contains other rules nested within it.

       CSSGROUPINGRULE

       The CSSGroupingRule interface of the CSS Object Model represents any CSS at-rule that contains other rules nested within it.

       INSTANCE PROPERTIES

       _This interface also inherits properties from CSSRule._

        * CSSGroupingRule.cssRules (read-only)
          * : Returns a CSSRuleList of the CSS rules in the media rule.

       INSTANCE METHODS

       _This interface also inherits methods from CSSRule._

        * CSSGroupingRule.deleteRule
          * : Deletes a rule from the style sheet.
        * CSSGroupingRule.insertRule
          * : Inserts a new style rule into the current style sheet.
