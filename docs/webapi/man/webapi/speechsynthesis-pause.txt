       NAME

       SpeechSynthesis: pause() method - The pause() method of the SpeechSynthesis

       SPEECHSYNTHESIS: PAUSE() METHOD

       The pause() method of the SpeechSynthesis interface puts the SpeechSynthesis object into a paused state.

       SYNTAX

         pause()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         const synth = window.speechSynthesis;

         const utterance1 = new SpeechSynthesisUtterance(
           "How about we say this now? This is quite a long sentence to say.",
         );
         const utterance2 = new SpeechSynthesisUtterance(
           "We should say another sentence too, just to be on the safe side.",
         );

         synth.speak(utterance1);
         synth.speak(utterance2);

         synth.pause(); // pauses utterances being spoken
