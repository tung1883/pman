       NAME

       Document: createTextNode() method - Creates a new Text node. This method can be used to escape HTML

       DOCUMENT: CREATETEXTNODE() METHOD

       Creates a new Text node. This method can be used to escape HTML characters.

       SYNTAX

         createTextNode(data)

       PARAMETERS

        * data
          * : A string containing the data to be put in the text node.

       RETURN VALUE

       A Text node.

       EXAMPLES

         <button>YES!</button>
         <button>NO!</button>
         <button>WE CAN!</button>

         <hr />

         <p id="p1">First line of paragraph.</p>

         function addTextNode(text) {
           const newText = document.createTextNode(text);
           const p1 = document.getElementById("p1");

           p1.appendChild(newText);
         }

         document.querySelectorAll("button").forEach((button) => {
           button.addEventListener("click", (event) => {
             addTextNode(`${event.target.textContent} `);
           });
         });
