       NAME

       Element: scrollTopMax property - The Element.scrollTopMax read-only property returns a

       ELEMENT: SCROLLTOPMAX PROPERTY

       {{Non-standard_header}}

       The Element.scrollTopMax read-only property returns a number representing the maximum top scroll offset possible for the element.

       VALUE

       A number.

       SPECIFICATIONS

       _This property is not part of any specification._

       BROWSER COMPATIBILITY

       SEE ALSO

        * Element.scrollLeftMax giving the same information for the other axis.
