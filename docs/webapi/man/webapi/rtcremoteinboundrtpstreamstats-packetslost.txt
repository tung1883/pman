       RTCREMOTEINBOUNDRTPSTREAMSTATS: PACKETSLOST PROPERTY

       The packetsLost property of the RTCRemoteInboundRtpStreamStats dictionary returns the total number of RTP packets lost from the synchronization source (SSRC), as reported by the remote endpoint, since the beginning of reception.

       VALUE

       An integer value indicating the number of lost RTP packets.

       This value can be negative. It is determined by subtracting the number of packets received from the number of packets that are expected. The number of packets that are expected is calculated in a way that assumes that all packets only need to be sent once (based on sequence numbers), while the number of packets received also includes any packets that had to be resent (and hence may be bigger). For more information see the "cumulative number of packets lost" section in 3550.
