       NAME

       MediaQueryList: media property - The media read-only property of the

       MEDIAQUERYLIST: MEDIA PROPERTY

       The media read-only property of the MediaQueryList interface is a string representing a serialized media query.

       VALUE

       A string representing a serialized media query.

       EXAMPLES

       This example runs the media query (width <= 600px) and displays the value of the resulting MediaQueryList's media property in a .

       JAVASCRIPT

         let mql = window.matchMedia("(width <= 600px)");

         document.querySelector(".mq-value").innerText = mql.media;

       The JavaScript code passes the media query to match into matchMedia() to compile it, then sets the 's innerText to the value of the result's media property.

       HTML

         <span class="mq-value"></span>

       A to receive the output.

             18px "Arial",
             sans-serif;
           font-weight: bold;

           border: 1px solid #ddddee;
         }
