       NAME

       FontFaceSet: keys() method - The keys() method of the FontFaceSet interface is an alias for FontFaceSet.values.

       FONTFACESET: KEYS() METHOD

       The keys() method of the FontFaceSet interface is an alias for FontFaceSet.values.

       SYNTAX

         keys()

       PARAMETERS

       None.

       RETURN VALUE

       A new iterator object containing the values for each element in the given FontFaceSet, in insertion order.
