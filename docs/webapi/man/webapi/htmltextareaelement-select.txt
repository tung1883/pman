       HTMLTEXTAREAELEMENT: SELECT() METHOD

       The select() method of the HTMLTextAreaElement interface selects the entire contents of the element. In addition, the select event is fired. The select() method does not take any parameters and does not return a value.

       SYNTAX

         select()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         const textarea = document.getElementById("text-box");
         textarea.select();
