       NAME

       DOMTokenList: values() method - The values() method of the DOMTokenList interface

       DOMTOKENLIST: VALUES() METHOD

       The values() method of the DOMTokenList interface returns an iterator allowing the caller to go through all values contained in the DOMTokenList. The individual values are strings.

       SYNTAX

         values()

       PARAMETERS

       None.

       RETURN VALUE

       Returns an iterator.

       EXAMPLES

       In the following example we retrieve the list of classes set on a element as a DOMTokenList using Element.classList. We when retrieve an iterator containing the values using values(), then iterate through those values using a for...of loop, writing each one to the 's Node.textContent.

       First, the HTML:

         <span class="a b c"></span>

       Now the JavaScript:

         const span = document.querySelector("span");
         const classes = span.classList;
         const iterator = classes.values();

         for (const value of iterator) {
           span.textContent += `(${value}) `;
         }
