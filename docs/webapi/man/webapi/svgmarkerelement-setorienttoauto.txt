WEBAPI.SVGMARKERELEMENT-SETORIENTTOAUTO(1) Sandbox manual WEBAPI.SVGMARKERELEMENT-SETORIENTTOAUTO(1)

       NAME

       SVGMarkerElement: setOrientToAuto() method - The setOrientToAuto() method of the SVGMarkerElement interface sets the value of the orient attribute to auto.

       SVGMARKERELEMENT: SETORIENTTOAUTO() METHOD

       The setOrientToAuto() method of the SVGMarkerElement interface sets the value of the orient attribute to auto.

       SYNTAX

         setOrientToAuto()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       In the following example the value of the orient attribute is updated using setOrientToAuto().

         <svg id="svg" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
           <defs>
             <marker
               id="arrow"
               viewBox="0 0 10 10"
               refX="5"
               refY="5"
               markerWidth="6"
               markerHeight="6"
               orient="90">
               <path d="M 0 0 L 10 5 L 0 10 z" />
             </marker>
           </defs>
         </svg>

         let marker = document.getElementById("arrow");
         console.log(marker.orientAngle.baseVal.value);
         marker.setOrientToAuto();
         console.log(marker.orientAngle.baseVal.value);
