       NAME

       SVGFilterElement: height property - The height read-only property of the SVGFilterElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLengt

       SVGFILTERELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFilterElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the height attribute of the filter element. The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const filter = document.querySelector("filter");
         const verticalSize = filter.height;
         console.log(verticalSize.baseVal.value); // the `height` value
