       NAME

       SVGNumberList: numberOfItems property - The numberOfItems property of the SVGNumberList interface returns the number of items in the list. length is an alias of it.

       SVGNUMBERLIST: NUMBEROFITEMS PROPERTY

       The numberOfItems property of the SVGNumberList interface returns the number of items in the list. length is an alias of it.

       VALUE

       A non-negative integer that represents the number of items in the list.
