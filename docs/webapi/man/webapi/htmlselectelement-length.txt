       NAME

       HTMLSelectElement: length property - The length property of the HTMLSelectElement interface specifies the number of <option> elements in the <select> element. It represents the 

       HTMLSELECTELEMENT: LENGTH PROPERTY

       The length property of the HTMLSelectElement interface specifies the number of elements in the element. It represents the number of nodes in the options collection. On setting, it acts as (HTMLOptionsCollection.length).

       VALUE

       A number.

       EXAMPLES

         const selectElement = document.getElementById("fruits");
         console.log(selectElement.length);
