       NAME

       FontFace: weight property - The weight property of the FontFace interface retrieves or sets the weight of the font.

       FONTFACE: WEIGHT PROPERTY

       The weight property of the FontFace interface retrieves or sets the weight of the font.

       This property is equivalent to the font-weight descriptor.

       VALUE

       A string containing a descriptor as it would be defined in a style sheet's @font-face rule.
