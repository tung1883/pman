WEBAPI.HTMLIFRAMEELEMENT-ALLOWPAYMENTREQUEST(1) Sandbox manual WEBAPI.HTMLIFRAMEELEMENT-ALLOWPAYMENTREQUEST(1)

       NAME

       HTMLIFrameElement: allowPaymentRequest property - The allowPaymentRequest property of the

       HTMLIFRAMEELEMENT: ALLOWPAYMENTREQUEST PROPERTY

       {{Non-standard_Header}}

       The allowPaymentRequest property of the HTMLIFrameElement interface returns a boolean value indicating whether the Payment Request API may be invoked on a cross-origin iframe.

       VALUE

       A boolean value.
