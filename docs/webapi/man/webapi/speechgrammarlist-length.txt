       NAME

       SpeechGrammarList: length property - The length read-only property of the

       SPEECHGRAMMARLIST: LENGTH PROPERTY

       The length read-only property of the SpeechGrammarList interface returns the number of SpeechGrammar objects contained in the SpeechGrammarList.

       VALUE

       A number indicating the number of SpeechGrammar objects contained in the SpeechGrammarList.
