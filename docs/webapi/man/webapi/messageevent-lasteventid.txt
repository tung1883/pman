       NAME

       MessageEvent: lastEventId property - The lastEventId read-only property of the

       MESSAGEEVENT: LASTEVENTID PROPERTY

       The lastEventId read-only property of the MessageEvent interface is a string representing a unique ID for the event.

       VALUE

       A string representing the ID.

       EXAMPLES

         myWorker.onmessage = (e) => {
           result.textContent = e.data;
           console.log("Message received from worker");
           console.log(e.lastEventId);
         };
