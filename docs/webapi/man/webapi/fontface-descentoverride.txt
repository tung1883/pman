WEBAPI.FONTFACE-DESCENTOVERRIDE(1) Sandbox manual WEBAPI.FONTFACE-DESCENTOVERRIDE(1)

       NAME

       FontFace: descentOverride property - The descentOverride property of the FontFace interface returns and sets the value of the @font-face/descent-override descriptor.

       FONTFACE: DESCENTOVERRIDE PROPERTY

       The descentOverride property of the FontFace interface returns and sets the value of the @font-face/descent-override descriptor. The possible values are normal, indicating that the metric used should be obtained from the font file, or a percentage.

       VALUE

       A string.

       EXAMPLES

         let fontFace = new FontFace(
           "Roboto",
           'url("https://fonts.example.com/roboto.woff2")',
           { descentOverride: "90%" },
         );
         console.log(fontFace.descentOverride); // 90%
         fontFace.descentOverride = "normal";
         console.log(fontFace.descentOverride); // 'normal'
