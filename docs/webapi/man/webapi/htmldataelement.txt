       HTMLDATAELEMENT

       The HTMLDataElement interface provides special properties (beyond the regular HTMLElement interface it also has available to it by inheritance) for manipulating elements.

       INSTANCE PROPERTIES

       _Inherits properties from its parent, HTMLElement._

        * HTMLDataElement.value
          * : A string reflecting the value HTML attribute, containing a machine-readable form of the element's value.

       INSTANCE METHODS

       _No specific method; inherits methods from its parent, HTMLElement._
