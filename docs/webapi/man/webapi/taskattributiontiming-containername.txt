       NAME

       TaskAttributionTiming: containerName property - The containerName read-only property of the TaskAttributionTiming interface returns the container's name

       TASKATTRIBUTIONTIMING: CONTAINERNAME PROPERTY

       The containerName read-only property of the TaskAttributionTiming interface returns the container's name attribute. A container is the iframe, embed or object etc. that is being implicated, on the whole, for a long task.

       VALUE

       A string containing the container's name HTML content attribute (e.g., or ).
