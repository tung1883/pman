       HTMLINPUTELEMENT: SRC PROPERTY

       The src property of the HTMLInputElement interface specifies the source of an image to display as the graphical submit button. It reflects the element's src attribute.

       The src property is valid for the image type only.

       VALUE

       A string.

       EXAMPLES

         const inputElement = document.getElementById("imageButton");
         console.log(inputElement.src);
