       NAME

       WorkerLocation: href property - worker

       WORKERLOCATION: HREF PROPERTY

       worker

       The href property of a WorkerLocation object returns a string containing the serialized URL for the worker's location.

       VALUE

       A string.

       EXAMPLES

         // In a Web worker, on the page https://developer.mozilla.org/en-US/docs/Web
         const result = location.href; // Returns 'https://developer.mozilla.org/en-US/docs/Web'
