       NAME

       Selection: extend() method - The Selection.extend() method moves the focus of the

       SELECTION: EXTEND() METHOD

       The Selection.extend() method moves the focus of the selection to a specified point. The anchor of the selection does not move. The selection will be from the anchor to the new focus, regardless of direction.

       SYNTAX

         extend(node)
         extend(node, offset)

       PARAMETERS

        * node
          * : The node within which the focus will be moved.
        * offset (optional)
          * : The offset position within node where the focus will be moved to. If
       not specified, the default value 0 is used.

       RETURN VALUE

       None (undefined).

       BROWSER COMPATIBILITY
