WEBAPI.HTMLPROGRESSELEMENT-MAX(1) Sandbox manual WEBAPI.HTMLPROGRESSELEMENT-MAX(1)

       NAME

       HTMLProgressElement: max property - The max property of the HTMLProgressElement interface represents the upper bound of the <progress> element's range.

       HTMLPROGRESSELEMENT: MAX PROPERTY

       The max property of the HTMLProgressElement interface represents the upper bound of the element's range.

       VALUE

       A floating point number that is greater than zero. The default value is 1.0.

       EXAMPLES

       HTML

         Progress: <progress id="pBar"></progress> <span>0</span>%

       JAVASCRIPT

         const pBar = document.getElementById("pBar");
         const span = document.getElementsByTagName("span")[0];

         console.log(`Default value of max: ${pBar.max}`);

         pBar.max = 100;
         pBar.value = 0;

         setInterval(() => {
           pBar.value = pBar.value < pBar.max ? pBar.value + 1 : 0;

           span.textContent = Math.trunc(pBar.position * 100);
         }, 100);
