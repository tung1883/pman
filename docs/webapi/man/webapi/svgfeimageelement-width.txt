       NAME

       SVGFEImageElement: width property - The width read-only property of the SVGFEImageElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLen

       SVGFEIMAGEELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFEImageElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the width attribute of the feImage element, which fetches image data from an external source and provides the pixel data as output. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feImage = document.querySelector("feImage");
         const horizontalSize = feImage.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
