       NAME

       Range: setEndAfter() method - The Range.setEndAfter() method sets the end position of a

       RANGE: SETENDAFTER() METHOD

       The Range.setEndAfter() method sets the end position of a Range relative to another Node. The parent Node of end of the Range will be the same as that for the referenceNode.

       SYNTAX

         setEndAfter(referenceNode)

       PARAMETERS

        * referenceNode
          * : The Node to end the Range after.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         const range = document.createRange();
         const referenceNode = document.getElementsByTagName("div").item(0);

         range.setEndAfter(referenceNode);
