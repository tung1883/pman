       NAME

       EXT_disjoint_timer_query: createQueryEXT() method - The EXTdisjointtimerquery.createQueryEXT() method of

       EXT_DISJOINT_TIMER_QUERY: CREATEQUERYEXT() METHOD

       The EXT_disjoint_timer_query.createQueryEXT() method of the WebGL API creates and initializes WebGLQuery objects, which track the time needed to fully complete a set of GL commands.

       SYNTAX

         createQueryEXT()

       PARAMETERS

       None.

       RETURN VALUE

       A WebGLQuery object.

       EXAMPLES

         const ext = gl.getExtension("EXT_disjoint_timer_query");
         const query = ext.createQueryExt();
