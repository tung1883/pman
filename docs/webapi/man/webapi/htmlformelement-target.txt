       NAME

       HTMLFormElement: target property - The target property of the HTMLFormElement

       HTMLFORMELEMENT: TARGET PROPERTY

       The target property of the HTMLFormElement interface represents the target of the form's action (i.e., the frame in which to render its output).

       VALUE

       A string.

       EXAMPLES

         myForm.target = frames[1].name;
