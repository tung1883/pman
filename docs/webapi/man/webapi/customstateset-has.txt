       NAME

       CustomStateSet: has() method - The has() method of the CustomStateSet interface returns a Boolean asserting whether an element is present with the given value.

       CUSTOMSTATESET: HAS() METHOD

       The has() method of the CustomStateSet interface returns a Boolean asserting whether an element is present with the given value.

       SYNTAX

         has(value)

       PARAMETERS

        * value
          * : The value to test for in the CustomStateSet object.

       RETURN VALUE

       A Boolean, true if value exists in the CustomStateSet.
