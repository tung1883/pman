WEBAPI.VISUALVIEWPORT-OFFSETTOP(1) Sandbox manual WEBAPI.VISUALVIEWPORT-OFFSETTOP(1)

       NAME

       VisualViewport: offsetTop property - The offsetTop read-only property of the VisualViewport interface returns the offset of the top edge of the visual viewport from the top edge

       VISUALVIEWPORT: OFFSETTOP PROPERTY

       The offsetTop read-only property of the VisualViewport interface returns the offset of the top edge of the visual viewport from the top edge of the layout viewport in CSS pixels, or 0 if current document is not fully active.

       VALUE

       A double.
