       NAME

       HTMLSelectElement: willValidate property - The willValidate read-only property of the HTMLSelectElement interface indicates whether the <select> element is a candidate for constraint 

       HTMLSELECTELEMENT: WILLVALIDATE PROPERTY

       The willValidate read-only property of the HTMLSelectElement interface indicates whether the element is a candidate for constraint validation. It is false if any conditions bar it from constraint validation, such as when its disabled property is true.

       VALUE

       A boolean value.
