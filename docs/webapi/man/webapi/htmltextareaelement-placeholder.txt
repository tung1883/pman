       HTMLTEXTAREAELEMENT: PLACEHOLDER PROPERTY

       The placeholder property of the HTMLTextAreaElement interface represents a hint to the user of what can be entered in the control. It reflects the element's placeholder attribute.

       VALUE

       A string.

       EXAMPLES

         const textareaElement = document.getElementById("comment");
         console.log(textArea.placeholder);
