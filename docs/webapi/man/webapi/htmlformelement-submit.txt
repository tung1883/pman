       NAME

       HTMLFormElement: submit() method - The HTMLFormElement.submit() method submits a given

       HTMLFORMELEMENT: SUBMIT() METHOD

       The HTMLFormElement.submit() method submits a given .

       This method is similar, but not identical to, activating a form's submit . When invoking this method directly, however:

        * No submit event is raised. In particular, the form's onsubmit event handler is not run.
        * Constraint validation is not triggered.
       The HTMLFormElement.requestSubmit() method is identical to activating a form's submit and does not have these differences.

       A form control (such as a submit button) with a name or id of submit will mask the form's submit method. Trying to call myForm.submit(); throws an error "submit is not a function" because in this case submit refers to the form control which has a name or id of submit.

       with attribute type="submit" will not be submitted with the form when using HTMLFormElement.submit(), but it would be submitted when you do it with original HTML form submit.

       SYNTAX

         submit()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

         document.forms["my-form"].submit();
