       NAME

       Window: fullScreen property - The fullScreen property of the Window

       WINDOW: FULLSCREEN PROPERTY

       {{Non-standard_Header}}

       The fullScreen property of the Window interface indicates whether the window is displayed in fullscreen mode or not.

       VALUE

       A boolean value with true meaning that the window is in fullscreen mode and false meaning it isn't.

       NOTES

        * Switching between regular window and full screen will fire the "resize" event on the
       corresponding window.

       EXAMPLES

         if (window.fullScreen) {
           // it's fullscreen!
         } else {
           // not fullscreen!
         }
