WEBAPI.URL-TOSTRING(1)           Sandbox manual           WEBAPI.URL-TOSTRING(1)

       NAME

       URL: toString() method - The toString() method of the URL interface returns a string containing the whole URL, which is the same value as URL.href.

       URL: TOSTRING() METHOD

       The toString() method of the URL interface returns a string containing the whole URL, which is the same value as URL.href.

       SYNTAX

         toString()

       PARAMETERS

       None.

       RETURN VALUE

       A string.

       EXAMPLES

         const url = new URL(
           "https://developer.mozilla.org/en-US/docs/Web/API/URL/toString",
         );
         url.toString(); // should return the URL as a string
