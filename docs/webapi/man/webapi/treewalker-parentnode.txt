       NAME

       TreeWalker: parentNode() method - The TreeWalker.parentNode() method moves the current

       TREEWALKER: PARENTNODE() METHOD

       The TreeWalker.parentNode() method moves the current Node to the first _visible_ ancestor node in the document order, and returns the found node. If no such node exists, or if it is above the TreeWalker's _root node_, it returns null and the current node is not changed.

       SYNTAX

         parentNode()

       PARAMETERS

       None.

       RETURN VALUE

       A Node object or null.

       EXAMPLES

         const treeWalker = document.createTreeWalker(
           document.body,
           NodeFilter.SHOW_ELEMENT,
           {
             acceptNode(node) {
               return NodeFilter.FILTER_ACCEPT;
             },
           },
           false,
         );
         const node = treeWalker.parentNode(); // returns null as there is no parent
