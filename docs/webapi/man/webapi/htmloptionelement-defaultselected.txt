       HTMLOptionElement: defaultSelected property - The defaultSelected property of the HTMLOptionElement interface specifies the default selected state of the element. This property reflects 

       HTMLOPTIONELEMENT: DEFAULTSELECTED PROPERTY

       The defaultSelected property of the HTMLOptionElement interface specifies the default selected state of the element. This property reflects the element's selected attribute. The presence of the selected attribute sets the defaultSelected property to true.

       VALUE

       A boolean.

       EXAMPLES

         const optionElement = document.getElementById("water");
         console.log(optionElement.defaultSelected);
