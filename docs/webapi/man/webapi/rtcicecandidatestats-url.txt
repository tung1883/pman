       NAME

       RTCIceCandidateStats: url property - The RTCIceCandidateStats dictionary's

       RTCICECANDIDATESTATS: URL PROPERTY

       The RTCIceCandidateStats dictionary's url property specifies the URL of the ICE server from which the described candidate was obtained. This property is _only_ available for local candidates.

       VALUE

       A string specifying the URL of the ICE server from which the candidate described by the RTCIceCandidateStats was obtained. This is the same URL that would be received in the icecandidate event's url property.

       > This property does not exist for remote candidates.
