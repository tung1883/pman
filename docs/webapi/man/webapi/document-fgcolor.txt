       NAME

       Document: fgColor property - fgColor gets/sets the foreground color, or text color, of

       DOCUMENT: FGCOLOR PROPERTY

       fgColor gets/sets the foreground color, or text color, of the current document.

       VALUE

       A string representing the color as a word (e.g., "red") or hexadecimal value (e.g., "#ff0000").

       EXAMPLES

         document.fgColor = "white";
         document.bgColor = "darkblue";

       NOTES

       The default value for this property in Mozilla Firefox is black (#000000 in hexadecimal).

       document.fgColor is deprecated in the HTML specification. The recommended alternative is the CSS property color (e.g., document.body.style.color = "red").
