       NAME

       SVGFETurbulenceElement: width property - The width read-only property of the SVGFETurbulenceElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimat

       SVGFETURBULENCEELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFETurbulenceElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the width attribute of the feTurbulence element, which allows the synthesis of artificial textures. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feTurbulence = document.querySelector("feTurbulence");
         const horizontalSize = feTurbulence.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
