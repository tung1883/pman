       NAME

       TransformStreamDefaultController: terminate() method - The terminate() method of the TransformStreamDefaultController interface closes the readable side and errors the writable side of the stream

       TRANSFORMSTREAMDEFAULTCONTROLLER: TERMINATE() METHOD

       The terminate() method of the TransformStreamDefaultController interface closes the readable side and errors the writable side of the stream.

       SYNTAX

         terminate()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       In the below example the terminate() method is called on a TransformStreamDefaultController.

         controller.terminate();
