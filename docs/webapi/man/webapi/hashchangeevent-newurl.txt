WEBAPI.HASHCHANGEEVENT-NEWURL(1) Sandbox manual WEBAPI.HASHCHANGEEVENT-NEWURL(1)

       NAME

       HashChangeEvent: newURL property - The newURL read-only property of the

       HASHCHANGEEVENT: NEWURL PROPERTY

       The newURL read-only property of the HashChangeEvent interface returns the new URL to which the window is navigating.

       VALUE

       A string.

       EXAMPLES

         window.addEventListener("hashchange", (event) => {
           console.log(`Hash changed to ${event.newURL}`);
         });
