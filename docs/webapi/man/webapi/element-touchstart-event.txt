       NAME

       Element: touchstart event - The touchstart event is fired when one or more touch points are placed on the touch surface.

       ELEMENT: TOUCHSTART EVENT

       The touchstart event is fired when one or more touch points are placed on the touch surface.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("touchstart", (event) => { })

         ontouchstart = (event) => { }

       EVENT TYPE

       A TouchEvent. Inherits from Event.

       TouchEvent

       Code samples for those events are available on the dedicated page: Touch events.
