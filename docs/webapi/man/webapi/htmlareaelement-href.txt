       NAME

       HTMLAreaElement: href property - The HTMLAreaElement.href property is a

       HTMLAREAELEMENT: HREF PROPERTY

       The HTMLAreaElement.href property is a stringifier that returns a string containing the whole URL, and allows the href to be updated.

       VALUE

       A string.

       EXAMPLES

         // An <area id="myArea" href="https://developer.mozilla.org/en-US/HTMLAreaElement"> element is in the document
         const area = document.getElementById("myArea");
         area.href; // returns 'https://developer.mozilla.org/en-US/HTMLAreaElement'
