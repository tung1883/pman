       NAME

       VideoDecoder: close() method - windowanddedicated

       VIDEODECODER: CLOSE() METHOD

       window_and_dedicated

       The close() method of the VideoDecoder interface ends all pending work and releases system resources.

       SYNTAX

         close()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       The following example closes the VideoDecoder.

         VideoDecoder.close();
