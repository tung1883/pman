WEBAPI.HASHCHANGEEVENT-OLDURL(1) Sandbox manual WEBAPI.HASHCHANGEEVENT-OLDURL(1)

       NAME

       HashChangeEvent: oldURL property - The oldURL read-only property of the

       HASHCHANGEEVENT: OLDURL PROPERTY

       The oldURL read-only property of the HashChangeEvent interface returns the previous URL from which the window was navigated.

       VALUE

       A string.

       EXAMPLES

         window.addEventListener("hashchange", (event) => {
           console.log(`Hash changed from ${event.oldURL}`);
         });
