       NAME

       SVGFEFloodElement: width property - The width read-only property of the SVGFEFloodElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLen

       SVGFEFLOODELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFEFloodElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the width attribute of the feFlood element, which fills an SVG filter subregion with the color and opacity defined by flood-color and flood-opacity. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feFlood = document.querySelector("feFlood");
         const horizontalSize = feFlood.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
