       NAME

       CloseEvent: reason property - The reason read-only property of the CloseEvent interface returns the WebSocket connection close reason the server gave for closing the conn

       CLOSEEVENT: REASON PROPERTY

       The reason read-only property of the CloseEvent interface returns the WebSocket connection close reason the server gave for closing the connection; that is, a concise human-readable prose explanation for the closure.

       VALUE

       A string.

       EXAMPLES

       The following example prints the value of reason to the console.

         WebSocket.onclose = (event) => {
           console.log(event.reason);
         };
