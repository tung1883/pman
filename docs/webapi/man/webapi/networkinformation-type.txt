       NAME

       NetworkInformation: type property - The type read-only property of the NetworkInformation interface returns the type of connection a device is using to communicate with the net

       NETWORKINFORMATION: TYPE PROPERTY

       The type read-only property of the NetworkInformation interface returns the type of connection a device is using to communicate with the network.

       VALUE

       An enumerated value that is one of the following values:

        * "bluetooth"
        * "cellular"
        * "ethernet"
        * "none"
        * "wifi"
        * "wimax"
        * "other"
        * "unknown"
