       NAME

       Notification: show event - The show event of the Notification interface fires when a Notification is displayed.

       NOTIFICATION: SHOW EVENT

       The show event of the Notification interface fires when a Notification is displayed.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("show", (event) => { })

         onshow = (event) => { }

       EVENT TYPE

       A generic Event.
