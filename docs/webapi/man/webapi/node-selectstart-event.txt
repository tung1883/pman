WEBAPI.NODE-SELECTSTART-EVENT(1) Sandbox manual WEBAPI.NODE-SELECTSTART-EVENT(1)

       NAME

       Node: selectstart event - The selectstart event of the Selection API is fired when a user starts a new selection.

       NODE: SELECTSTART EVENT

       The selectstart event of the Selection API is fired when a user starts a new selection.

       If the event is canceled, the selection is not changed.

       SYNTAX

       Use the event name in methods like addEventListener(), or set an event handler property.

         addEventListener("selectstart", (event) => { })

         onselectstart = (event) => { }

       EVENT TYPE

       A generic Event.

       EXAMPLES

         // addEventListener version
         document.addEventListener("selectstart", () => {
           console.log("Selection started");
         });

         // onselectstart version
         document.onselectstart = () => {
           console.log("Selection started.");
         };
