       NAME

       ServiceWorkerRegistration: index property - The index read-only property of the

       SERVICEWORKERREGISTRATION: INDEX PROPERTY

       The index read-only property of the ServiceWorkerRegistration interface returns a reference to the ContentIndex interface, which allows for indexing of offline content.

       VALUE

       A ContentIndex object.

       EXAMPLES

       You can access the property from either your main script or the registered service worker.

       Here is an example from the main script:

         // reference registration
         const registration = await navigator.serviceWorker.ready;

         // feature detection
         if ("index" in registration) {
           // Content Index API functionality
           const contentIndex = registration.index;
         }

       From the service worker:

         // service worker script

         const contentIndex = self.registration.index;
