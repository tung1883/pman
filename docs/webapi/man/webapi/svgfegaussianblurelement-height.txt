       SVGFEGAUSSIANBLURELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFEGaussianBlurElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the height attribute of the feGaussianBlur element, which blurs an input image. The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feGaussianBlur = document.querySelector("feGaussianBlur");
         const verticalSize = feGaussianBlur.height;
         console.log(verticalSize.baseVal.value); // the `height` value
