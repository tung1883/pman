WEBAPI.CRYPTO-RANDOMUUID(1)      Sandbox manual      WEBAPI.CRYPTO-RANDOMUUID(1)

       NAME

       Crypto: randomUUID() method - The randomUUID() method of the Crypto interface is used to generate a v4 UUID using a cryptographically secure random number generator.

       CRYPTO: RANDOMUUID() METHOD

       The randomUUID() method of the Crypto interface is used to generate a v4 UUID using a cryptographically secure random number generator.

       SYNTAX

         randomUUID()

       PARAMETERS

       None.

       RETURN VALUE

       A string containing a randomly generated, 36 character long v4 UUID.

       EXAMPLES

         /* Assuming that self.crypto.randomUUID() is available */

         let uuid = self.crypto.randomUUID();
         console.log(uuid); // for example "36b8f84d-df4e-4d49-b662-bcde71a8764f"
