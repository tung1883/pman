       HTMLOPTIONELEMENT: INDEX PROPERTY

       The read-only index property of the HTMLOptionElement interface specifies the 0-based index of the element; that is, the position of the within the list of options it belongs to, in tree-order, as an integer. If the is not part of an option-list, the value is 0.

       VALUE

       A number.

       EXAMPLES

         const optionElement = document.getElementById("myOption");
         console.log(optionElement.index);
