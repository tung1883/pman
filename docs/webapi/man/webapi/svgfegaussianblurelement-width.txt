       NAME

       SVGFEGaussianBlurElement: width property - The width read-only property of the SVGFEGaussianBlurElement interface describes the horizontal size of an SVG filter primitive as a SVGAnim

       SVGFEGAUSSIANBLURELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFEGaussianBlurElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the width attribute of the feGaussianBlur element, which blurs an input image. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feGaussianBlur = document.querySelector("feGaussianBlur");
         const horizontalSize = feGaussianBlur.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
