       MATHMLELEMENT: AUTOFOCUS PROPERTY

       The autofocus property of the MathMLElement interface contains a boolean value reflecting the autofocus HTML global attribute. It indicates whether the MathML element should be focused when the page loads or when the element becomes shown if the MathML element is inside a or a popover.

       VALUE

       A boolean value.
