       NAME

       ShadowRoot: styleSheets property - The styleSheets read-only property of the ShadowRoot interface

       SHADOWROOT: STYLESHEETS PROPERTY

       The styleSheets read-only property of the ShadowRoot interface returns a StyleSheetList of CSSStyleSheet objects, for stylesheets explicitly linked into or embedded in a shadow tree.

       VALUE

       A StyleSheetList of CSSStyleSheet objects.

       EXAMPLES

         let customElem = document.querySelector("my-shadow-dom-element");
         let shadow = customElem.shadowRoot;
         let styleSheets = shadow.styleSheets;
