       SVGFILTERELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFilterElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the width attribute of the filter element. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const filter = document.querySelector("filter");
         const horizontalSize = filter.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
