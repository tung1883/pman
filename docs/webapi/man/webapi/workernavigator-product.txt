       NAME

       WorkerNavigator: product property - worker

       WORKERNAVIGATOR: PRODUCT PROPERTY

       worker

       The value of the WorkerNavigator.product property is always "Gecko", in any browser. This property is kept only for compatibility purposes.

       > Do not rely on this property to return a real product name. All browsers return "Gecko" as the value of this property.

       VALUE

       The string "Gecko".
