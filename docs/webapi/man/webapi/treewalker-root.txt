WEBAPI.TREEWALKER-ROOT(1)        Sandbox manual        WEBAPI.TREEWALKER-ROOT(1)

       NAME

       TreeWalker: root property - The TreeWalker.root read-only property returns the root Node that the TreeWalker traverses.

       TREEWALKER: ROOT PROPERTY

       The TreeWalker.root read-only property returns the root Node that the TreeWalker traverses.

       VALUE

       A Node object.

       EXAMPLES

         const treeWalker = document.createTreeWalker(
           document.body,
           NodeFilter.SHOW_ELEMENT,
           {
             acceptNode(node) {
               return NodeFilter.FILTER_ACCEPT;
             },
           },
           false,
         );
         root = treeWalker.root; // document.body in this case
