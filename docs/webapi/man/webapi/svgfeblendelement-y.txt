       SVGFEBLENDELEMENT: Y PROPERTY

       The y read-only property of the SVGFEBlendElement interface describes the vertical coordinate of the position of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feBlend element's y filter primitive attribute value. The SVG filter blends two input images together using commonly used imaging software blending modes.

       The attribute is a or . The is a length in the user coordinate system that is the given distance from the origin of the user coordinate system along the y-axis. If the y attribute is a percent value, the property value is a relative to the height of the filter region in user coordinate system units. The default value is 0.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feBlend = document.querySelector("feBlend");
         const topPosition = feBlend.y;
         console.log(topPosition.baseVal.value); // the `y` value
