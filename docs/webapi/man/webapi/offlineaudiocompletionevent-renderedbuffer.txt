       NAME

       OfflineAudioCompletionEvent: renderedBuffer property - The renderedBuffer read-only property of the

       OFFLINEAUDIOCOMPLETIONEVENT: RENDEREDBUFFER PROPERTY

       The renderedBuffer read-only property of the OfflineAudioCompletionEvent interface is an AudioBuffer containing the result of processing an OfflineAudioContext.

       VALUE

       An AudioBuffer.
