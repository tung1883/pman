       NAME

       Document: releaseCapture() method - The releaseCapture() method releases mouse capture if

       DOCUMENT: RELEASECAPTURE() METHOD

       {{Non-standard_header}}

       The releaseCapture() method releases mouse capture if it's currently enabled on an element within this document. Once mouse capture is released, mouse events will no longer all be directed to the element on which capture is enabled.

       Enabling mouse capture on an element is done by calling element.setCapture().

       SYNTAX

         releaseCapture()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       See the example for element.setCapture().

       SPECIFICATIONS

       Not part of any specification.

       BROWSER COMPATIBILITY

       SEE ALSO

        * element.setCapture()
