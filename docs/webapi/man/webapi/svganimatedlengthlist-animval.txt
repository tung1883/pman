       SVGANIMATEDLENGTHLIST: ANIMVAL PROPERTY

       The animVal read-only property of the SVGAnimatedLengthList interface represents the animated value of an attribute that accepts a list of , , or values.

       Some SVG attributes, like the x, y, dx, and dy attributes of the and elements, accept a list of length, percentages, or numbers as a value. This property provides access to the current animated state of the attribute as a live SVGLengthList object.

       VALUE

       An SVGLengthList object representing the animated value of the attribute.
