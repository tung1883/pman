       NAME

       HTMLSelectElement: setCustomValidity() method - The HTMLSelectElement.setCustomValidity() method sets the

       HTMLSELECTELEMENT: SETCUSTOMVALIDITY() METHOD

       The HTMLSelectElement.setCustomValidity() method sets the custom validity message for the selection element to the specified message. Use the empty string to indicate that the element does _not_ have a custom validity error.

       SYNTAX

         setCustomValidity(string)

       PARAMETERS

        * string
          * : The string containing the error message. The empty string removes any custom validity errors.

       RETURN VALUE

       None (undefined).
