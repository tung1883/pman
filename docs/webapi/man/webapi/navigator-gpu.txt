       NAME

       Navigator: gpu property - The Navigator.gpu read-only property returns the GPU object for the current browsing context, which is the entry point for the WebGPU API.

       NAVIGATOR: GPU PROPERTY

       The Navigator.gpu read-only property returns the GPU object for the current browsing context, which is the entry point for the WebGPU API.

       VALUE

       A GPU object.

       EXAMPLES

         async function init() {
           if (!navigator.gpu) {
             throw Error("WebGPU not supported.");
           }

           const adapter = await navigator.gpu.requestAdapter();
           if (!adapter) {
             throw Error("Couldn't request WebGPU adapter.");
           }

           const device = await adapter.requestDevice();

           // …
         }
