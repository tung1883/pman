       NAME

       HTMLInputElement: formNoValidate property - The formNoValidate property of the HTMLInputElement interface is a boolean value indicating if the <form> will bypass constraint validation 

       HTMLINPUTELEMENT: FORMNOVALIDATE PROPERTY

       The formNoValidate property of the HTMLInputElement interface is a boolean value indicating if the will bypass constraint validation when submitted via the . It reflects the element's formnovalidate attribute.

       This property is valid only for submit and image elements.

       Its value overrides the noValidate property of the HTMLFormElement interface if the form is submitted via the input. This property can be retrieved or set.

       VALUE

       A boolean.

       EXAMPLES

         const inputElement = document.getElementById("myInput");
         console.log(inputElement.formNoValidate);
