       NAME

       AudioBuffer: AudioBuffer() constructor - The AudioBuffer constructor of

       AUDIOBUFFER: AUDIOBUFFER() CONSTRUCTOR

       The AudioBuffer constructor of the Web Audio API creates a new AudioBuffer object.

       SYNTAX

         new AudioBuffer(options)

       PARAMETERS

        * options
          * : Options are as follows:
            * length
              * : The size of the audio buffer in sample-frames. To determine
       the length to use for a specific number of seconds of audio, use numSeconds * sampleRate.

            * numberOfChannels
              * : The number of channels for the buffer. The
       default is 1, and all user agents are required to support at least 32 channels.

            * sampleRate
              * : The sample rate in Hz for the buffer. The default is
       the sample rate of the context used in constructing this object. User agents are required to support sample rates from 8,000 Hz to 96,000 Hz (but are allowed to go farther outside this range).

       EXCEPTIONS

        * NotSupportedError DOMException
          * : Thrown if one or more of the options are negative or otherwise has an invalid value
       (such as numberOfChannels being higher than supported, or a sampleRate outside the nominal range).

        * RangeError
          * : Thrown if there isn't enough memory available to allocate the buffer.
