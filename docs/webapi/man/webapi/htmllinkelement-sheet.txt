       NAME

       HTMLLinkElement: sheet property - The sheet read-only property of the HTMLLinkElement interface

       HTMLLINKELEMENT: SHEET PROPERTY

       The sheet read-only property of the HTMLLinkElement interface contains the stylesheet associated with that element.

       A stylesheet is associated to an HTMLLinkElement if rel="stylesheet" is used with .

       VALUE

       A CSSStyleSheet object, or null if none is associated with the element.

       EXAMPLES

         <link rel="stylesheet" href="styles.css" />

       The sheet property of the HTMLLinkElement object will return the CSSStyleSheet object describing styles.css.
