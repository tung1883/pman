       NAME

       Highlight: keys() method - The keys() method of the Highlight interface is an alias for the values() method.

       HIGHLIGHT: KEYS() METHOD

       The keys() method of the Highlight interface is an alias for the values() method.

       Highlight is a Set-like object, so this is similar to using Set.keys().

       SYNTAX

         keys()

       PARAMETERS

       None.

       RETURN VALUE

       A new iterator object containing each AbstractRange object in the given Highlight, in insertion order.
