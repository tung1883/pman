       NAME

       SVGFEComponentTransferElement: height property - The height read-only property of the SVGFEComponentTransferElement interface describes the vertical size of an SVG filter primitive as a SVG

       SVGFECOMPONENTTRANSFERELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFEComponentTransferElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feComponentTransfer element's height filter primitive attribute. The filter performs component-wise color and alpha transparency remapping, allowing for brightness, contrast, color balance and threshold adjustments.

       The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feComponentTransfer = document.querySelector("feComponentTransfer");
         const verticalSize = feComponentTransfer.height;
         console.log(verticalSize.baseVal.value); // the `height` value
