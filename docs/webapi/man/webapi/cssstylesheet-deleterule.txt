       NAME

       CSSStyleSheet: deleteRule() method - The CSSStyleSheet method

       CSSSTYLESHEET: DELETERULE() METHOD

       The CSSStyleSheet method deleteRule() removes a rule from the stylesheet object.

       SYNTAX

         deleteRule(index)

       PARAMETERS

        * index
          * : The index into the stylesheet's CSSRuleList indicating the rule to be
       removed.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       This example removes the first rule from the stylesheet myStyles.

         myStyles.deleteRule(0);
