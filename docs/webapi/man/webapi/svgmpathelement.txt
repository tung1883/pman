       NAME

       SVGMPathElement - The SVGMPathElement interface corresponds to the mpath element.

       SVGMPATHELEMENT

       The SVGMPathElement interface corresponds to the mpath element.

       INSTANCE PROPERTIES

       _This interface also inherits properties from its parent, SVGElement._

        * SVGMPathElement.href (read-only)
          * : An SVGAnimatedString that corresponds to the href or xlink:href (deprecated) attribute of the given mpath element.

       INSTANCE METHODS

       _This interface doesn't implement any specific methods, but inherits methods from its parent interface, SVGElement._
