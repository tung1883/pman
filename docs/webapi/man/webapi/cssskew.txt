       NAME

       CSSSkew - The CSSSkew interface of the CSS Typed Object Model API represents the skew() value of the individual transform property in CSS.

       CSSSKEW

       The CSSSkew interface of the CSS Typed Object Model API represents the skew() value of the individual transform property in CSS.

       CONSTRUCTOR

        * CSSSkew()
          * : Creates a new CSSSkew object.

       INSTANCE PROPERTIES

       _Also inherits properties from its parent interface, CSSTransformComponent._

        * ax
          * : Returns or sets the x-axis value.
        * ay
          * : Returns or sets the y-axis value.
