       VIDEOTRACKGENERATOR: WRITABLE PROPERTY

       The writable property of the VideoTrackGenerator interface returns a WritableStream. This allows the writing of VideoFrames to the VideoTrackGenerator.track.

       VALUE

       A WritableStream of VideoFrames.

       See the Insertable Streams for MediaStreamTrack API for an example.
