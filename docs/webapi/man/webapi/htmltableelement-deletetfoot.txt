WEBAPI.HTMLTABLEELEMENT-DELETETFOOT(1) Sandbox manual WEBAPI.HTMLTABLEELEMENT-DELETETFOOT(1)

       NAME

       HTMLTableElement: deleteTFoot() method - The deleteTFoot() method of the HTMLTableElement interface removes the first <tfoot> element child from a given <table>, if any.

       HTMLTABLEELEMENT: DELETETFOOT() METHOD

       The deleteTFoot() method of the HTMLTableElement interface removes the first element child from a given , if any.

       SYNTAX

         deleteTFoot()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).

       EXAMPLES

       This example uses JavaScript to delete a table's footer.

       HTML

         <table>
           <thead>
             <tr>
               <th>Name</th>
               <th>Score</th>
             </tr>
           </thead>
           <tbody>
             <tr>
               <td>Bob</td>
               <td>541</td>
             </tr>
             <tr>
               <td>Jim</td>
               <td>225</td>
             </tr>
           </tbody>
           <tfoot>
             <tr>
               <th>Average</th>
               <td>383</td>
             </tr>
           </tfoot>
         </table>

       JAVASCRIPT

         const table = document.querySelector("table");
         table.deleteTFoot();
