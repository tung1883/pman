       NAME

       SVGFEDisplacementMapElement: width property - The width read-only property of the SVGFEDisplacementMapElement interface describes the horizontal size of an SVG filter primitive as a SVGA

       SVGFEDISPLACEMENTMAPELEMENT: WIDTH PROPERTY

       The width read-only property of the SVGFEDisplacementMapElement interface describes the horizontal size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the feDisplacementMap element's width filter primitive attribute. The attribute is a or a relative to the width of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feDisplacementMap = document.querySelector("feDisplacementMap");
         const horizontalSize = feDisplacementMap.width;
         console.log(horizontalSize.baseVal.value); // the `width` value
