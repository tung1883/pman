       NAME

       Document: firstElementChild property - The Document.firstElementChild read-only property

       DOCUMENT: FIRSTELEMENTCHILD PROPERTY

       The Document.firstElementChild read-only property returns the document's first child Element, or null if there are no child elements.

       For HTML documents, this is usually the only child, the root element.

       See Element.firstElementChild for the first child element of specific elements within a document.

       VALUE

       An Element object, or null.

       EXAMPLES

         document.firstElementChild;
         // returns the root <html> element, the only child of the document
