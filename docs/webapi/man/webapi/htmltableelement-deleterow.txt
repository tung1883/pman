       NAME

       HTMLTableElement: deleteRow() method - The deleteRow() method of the HTMLTableElement interface removes a specific row (<tr>) from a given <table>.

       HTMLTABLEELEMENT: DELETEROW() METHOD

       The deleteRow() method of the HTMLTableElement interface removes a specific row () from a given .

       SYNTAX

         deleteRow(index)

       PARAMETERS

        * index
          * : The index of the row to remove in the rows collection. If index is -1, the last row is removed.

       RETURN VALUE

       None (undefined).

       EXCEPTIONS

        * IndexSizeError DOMException
          * : Thrown if index is greater than or equal to the number of rows or smaller than -1.

       EXAMPLES

       This example uses JavaScript to delete a table's second row.

       HTML

         <table>
           <tbody>
             <tr>
               <td>Cell 1.1</td>
               <td>Cell 1.2</td>
               <td>Cell 1.3</td>
             </tr>
             <tr>
               <td>Cell 2.1</td>
               <td>Cell 2.2</td>
               <td>Cell 2.3</td>
             </tr>
             <tr>
               <td>Cell 3.1</td>
               <td>Cell 3.2</td>
               <td>Cell 3.3</td>
             </tr>
           </tbody>
         </table>

       JAVASCRIPT

         const table = document.querySelector("table");

         // Delete second row
         table.deleteRow(1);
