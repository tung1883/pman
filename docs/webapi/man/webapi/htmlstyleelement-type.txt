       NAME

       HTMLStyleElement: type property - The HTMLStyleElement.type property returns the type of the current style.

       HTMLSTYLEELEMENT: TYPE PROPERTY

       The HTMLStyleElement.type property returns the type of the current style. The value mirrors the HTML element's type attribute.

       Authors should not use this property or rely on the value.

       VALUE

       The permitted values are an empty string or a case-insensitive match for "text/css".
