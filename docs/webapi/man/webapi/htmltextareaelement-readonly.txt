       HTMLTEXTAREAELEMENT: READONLY PROPERTY

       The readOnly property of the HTMLTextAreaElement interface indicates that the user cannot modify the value of the control. Unlike the disabled attribute, the readonly attribute does not prevent the user from clicking or selecting in the control. It reflects the element's readonly attribute.

       VALUE

       A boolean.

       EXAMPLES

         const textareaElement = document.getElementById("comment");
         console.log(textArea.readOnly);
