       NAME

       SVGFETurbulenceElement: numOctaves property - The numOctaves read-only property of the SVGFETurbulenceElement interface reflects the numOctaves attribute of the given feTurbulence elemen

       SVGFETURBULENCEELEMENT: NUMOCTAVES PROPERTY

       The numOctaves read-only property of the SVGFETurbulenceElement interface reflects the numOctaves attribute of the given feTurbulence element.

       VALUE

       An SVGAnimatedInteger object.

       EXAMPLES

       ACCESSING THE NUMOCTAVES PROPERTY

         <svg viewBox="0 0 200 200" xmlns="http://www.w3.org/2000/svg">
           <defs>
             <filter id="turbulenceFilter">
               <feTurbulence type="fractalNoise" baseFrequency="0.05" numOctaves="4" />
             </filter>
           </defs>

           <rect
             x="20"
             y="20"
             width="160"
             height="160"
             fill="lightblue"
             filter="url(#turbulenceFilter)" />
         </svg>

         // Select the feTurbulence element
         const turbulenceElement = document.querySelector("feTurbulence");

         // Access the numOctaves property
         console.log(turbulenceElement.numOctaves.baseVal); // Output: 4
