       NAME

       MediaSource: clearLiveSeekableRange() method - windowanddedicated

       MEDIASOURCE: CLEARLIVESEEKABLERANGE() METHOD

       window_and_dedicated

       The clearLiveSeekableRange() method of the MediaSource interface clears a seekable range previously set with a call to setLiveSeekableRange().

       SYNTAX

         clearLiveSeekableRange()

       PARAMETERS

       None.

       RETURN VALUE

       None (undefined).
