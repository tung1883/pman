       NAME

       PerformanceTiming: secureConnectionStart property - > [!WARNING]

       PERFORMANCETIMING: SECURECONNECTIONSTART PROPERTY

       > This interface of this property is deprecated in the Navigation Timing Level 2 specification. Please use the PerformanceNavigationTiming interface instead.
       The legacy PerformanceTiming.secureConnectionStart read-only property returns an unsigned long long representing the moment, in milliseconds since the UNIX epoch, where the secure connection handshake starts. If no such connection is requested, it returns 0.

       VALUE

       An unsigned long long.
