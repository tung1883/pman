       NAME

       BaseAudioContext: createConstantSource() method - The createConstantSource()

       BASEAUDIOCONTEXT: CREATECONSTANTSOURCE() METHOD

       The createConstantSource() property of the BaseAudioContext interface creates a ConstantSourceNode object, which is an audio source that continuously outputs a monaural (one-channel) sound signal whose samples all have the same value.

       > The ConstantSourceNode()
       > constructor is the recommended way to create a ConstantSourceNode; see
       > Creating an AudioNode.

       SYNTAX

         createConstantSource()

       PARAMETERS

       None.

       RETURN VALUE

       A ConstantSourceNode instance.
