       NAME

       SVGFETileElement: x property - The x read-only property of the SVGFETileElement interface describes the horizontal coordinate of the position of an SVG filter primitive as

       SVGFETILEELEMENT: X PROPERTY

       The x read-only property of the SVGFETileElement interface describes the horizontal coordinate of the position of an SVG filter primitive as an SVGAnimatedLength.

       It reflects the x attribute of the feTile element, which fills a target rectangle with a repeated, tiled pattern of an input image. The attribute is a or . The is a length in the user coordinate system that is the given distance from the origin of the user coordinate system along the x-axis. If the x attribute is a percent value, the property value is relative to the width of the filter region in user coordinate system units. The default value is 0.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feTile = document.querySelector("feTile");
         const leftPosition = feTile.x;
         console.log(leftPosition.baseVal.value); // the `x` value
