       NAME

       PictureInPictureWindow: height property - The height read-only property of the PictureInPictureWindow interface returns the height of the floating video window in pixels.

       PICTUREINPICTUREWINDOW: HEIGHT PROPERTY

       The height read-only property of the PictureInPictureWindow interface returns the height of the floating video window in pixels.

       VALUE

       An integer value indicating the height of the floating video window in pixels if the Picture-in-Picture window is open. Otherwise, it returns 0.
