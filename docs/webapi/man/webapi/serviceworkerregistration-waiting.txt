       NAME

       ServiceWorkerRegistration: waiting property - The waiting read-only property of the

       SERVICEWORKERREGISTRATION: WAITING PROPERTY

       The waiting read-only property of the ServiceWorkerRegistration interface returns a service worker whose ServiceWorker.state is installed. This property is initially set to null.

       VALUE

       A ServiceWorker object, if it is currently in an installed state.
