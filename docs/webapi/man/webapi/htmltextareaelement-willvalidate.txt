       HTMLTEXTAREAELEMENT: WILLVALIDATE PROPERTY

       The willValidate read-only property of the HTMLTextAreaElement interface indicates whether the element is a candidate for constraint validation. It is false if any conditions bar it from constraint validation, such as when its disabled or readOnly property is true.

       VALUE

       A boolean value.
