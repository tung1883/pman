       NAME

       Navigator: userAgentData property - The userAgentData read-only property of the Navigator interface returns a NavigatorUAData object

       NAVIGATOR: USERAGENTDATA PROPERTY

       The userAgentData read-only property of the Navigator interface returns a NavigatorUAData object which can be used to access the User-Agent Client Hints API.

       VALUE

       A NavigatorUAData object.

       EXAMPLES

       The following example prints the value of NavigatorUAData.brands to the console.

         console.log(navigator.userAgentData.brands);
