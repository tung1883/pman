       NAME

       SVGFEDropShadowElement: height property - The height read-only property of the SVGFEDropShadowElement interface describes the vertical size of an SVG filter primitive as a SVGAnimate

       SVGFEDROPSHADOWELEMENT: HEIGHT PROPERTY

       The height read-only property of the SVGFEDropShadowElement interface describes the vertical size of an SVG filter primitive as a SVGAnimatedLength.

       It reflects the height filter primitive attribute. The attribute is a or a relative to the height of the filter region. The default value is 100%. The property value is a length in user coordinate system units.

       VALUE

       An SVGAnimatedLength.

       EXAMPLE

         const feDropShadow = document.querySelector("feDropShadow");
         const verticalSize = feDropShadow.height;
         console.log(verticalSize.baseVal.value); // the `height` value
