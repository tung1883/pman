       NAME

       MediaStreamEvent: stream property - The read-only property MediaStreamEvent.stream returns

       MEDIASTREAMEVENT: STREAM PROPERTY

       {{Non-standard_header}}

       The read-only property MediaStreamEvent.stream returns the MediaStream associated with the event.

       EXAMPLE

         pc.onaddstream = (ev) => {
           alert(`A stream (id: '${ev.stream.id}') has been added to this connection.`);
         };
