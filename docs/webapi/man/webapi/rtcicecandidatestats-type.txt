       NAME

       RTCIceCandidateStats: type property - The type property of the RTCIceCandidateStats dictionary is a string with the value "local-candidate".

       RTCICECANDIDATESTATS: TYPE PROPERTY

       The type property of the RTCIceCandidateStats dictionary is a string with the value "local-candidate".

       Different statistics are obtained by iterating the RTCStatsReport object returned by a call to RTCPeerConnection.getStats(). The type indicates the set of statistics available through the object in a particular iteration step. A value of "local-candidate" indicates that the statistics available in the current step are those defined in RTCIceCandidateStats.

       VALUE

       A string with the value "local-candidate".
