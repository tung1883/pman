       NAME

       WorkerLocation: protocol property - worker

       WORKERLOCATION: PROTOCOL PROPERTY

       worker

       The protocol property of a WorkerLocation object returns the protocol part of the worker's location.

       VALUE

       A string.

       EXAMPLES

         // In a Web worker, on the page https://developer.mozilla.org/en-US/docs/Web
         const result = location.protocol; // Returns 'https:'
