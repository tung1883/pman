       HTMLTEXTAREAELEMENT: TEXTLENGTH PROPERTY

       The textLength read-only property of the HTMLTextAreaElement interface is a non-negative integer representing the number of characters, in UTF-16 code units, of the element's value. It is a shortcut of accessing length on its value property.

       VALUE

       A non-negative integer.

       EXAMPLES

         const textareaElement = document.getElementById("comment");
         console.log(textArea.textLength);
