WEBAPI.HTMLSELECTELEMENT-OPTIONS(1) Sandbox manual WEBAPI.HTMLSELECTELEMENT-OPTIONS(1)

       NAME

       HTMLSelectElement: options property - The HTMLSelectElement.options read-only property returns

       HTMLSELECTELEMENT: OPTIONS PROPERTY

       The HTMLSelectElement.options read-only property returns a HTMLOptionsCollection of the elements contained by the element.

       VALUE

       A HTMLOptionsCollection containing the elements contained by the element.

       EXAMPLES

       HTML

         <label for="test">Label</label>
         <select id="test">
           <option value="1">Option 1</option>
           <option value="2">Option 2</option>
         </select>

       JAVASCRIPT

         const select = document.getElementById("test");
         for (const option of select.options) {
           console.log(option.label); // "Option 1" and "Option 2"
         }
