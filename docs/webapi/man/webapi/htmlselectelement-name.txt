WEBAPI.HTMLSELECTELEMENT-NAME(1) Sandbox manual WEBAPI.HTMLSELECTELEMENT-NAME(1)

       NAME

       HTMLSelectElement: name property - The name property of the HTMLSelectElement interface indicates the name of the <select> element. It reflects the element's name attribute.

       HTMLSELECTELEMENT: NAME PROPERTY

       The name property of the HTMLSelectElement interface indicates the name of the element. It reflects the element's name attribute.

       VALUE

       A string representing the element's name.

       EXAMPLE

         const selectElement = document.querySelector("#planets");
         console.log(`Element's name: ${selectElement.name}`);
         selectElement.name = "galaxies"; // sets or updates the element's name
