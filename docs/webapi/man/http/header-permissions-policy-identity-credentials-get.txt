       PERMISSIONS-POLICY: IDENTITY-CREDENTIALS-GET DIRECTIVE

       The HTTP Permissions-Policy header identity-credentials-get directive controls whether the current document is allowed to use the Federated Credential Management API (FedCM), and more specifically usage of the following methods:

        * navigator.credentials.get() (when used with the identity option)
        * IdentityCredential.disconnect()
        * IdentityProvider.getUserInfo()
       Where this policy forbids use of the API, Promises returned by these methods will reject with a NotAllowedError DOMException.

       SYNTAX

         Permissions-Policy: identity-credentials-get=<allowlist>;

        * 
          * : A list of origins for which permission is granted to use the feature. See Permissions-Policy > Syntax for more details.

       DEFAULT POLICY

       The default allowlist for identity-credentials-get is self.
