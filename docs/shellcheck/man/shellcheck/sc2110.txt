       NAME

       In [[..]], use || instead of -o. - -o for logical OR is not supported in a [[ .. ]] expression. Use || instead.

       IN .. , USE INSTEAD OF -O

       IN .. , USE INSTEAD OF -O

       PROBLEMATIC CODE

         [[ "$1" = "-v" -o "$1" = "-help" ]]

       CORRECT CODE

         [[ "$1" = "-v" || "$1" = "-help" ]]

       RATIONALE

       -o for logical OR is not supported in a [[ .. ]] expression. Use || instead.

       EXCEPTIONS

       None.
