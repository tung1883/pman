       NAME

       You need a space before the !. - while! [ -f file ]

       YOU NEED A SPACE BEFORE THE

       YOU NEED A SPACE BEFORE THE

       PROBLEMATIC CODE

         while! [ -f file ]
         do sleep 1; done

       CORRECT CODE

         while ! [ -f file ]
         do sleep 1; done

       RATIONALE

       ShellCheck found a keyword immediately followed by a !. There needs to be a space between them.

       EXCEPTIONS

       None
