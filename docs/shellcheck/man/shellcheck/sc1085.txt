       NAME

       Did you forget to move the ;; after extending this case item? - case $options in

       DID YOU FORGET TO MOVE THE AFTER EXTENDING THIS CASE ITEM

       DID YOU FORGET TO MOVE THE AFTER EXTENDING THIS CASE ITEM

       PROBLEMATIC CODE

         case $options in
           foobar) echo foo ;; echo bar;;
           *) echo unknown option ;;
         esac

       CORRECT CODE

         case $options in
           foobar) echo foo ; echo bar;;
           *) echo unknown option ;;
         esac

       RATIONALE

       There should be no statements between ;; and the next case item.
