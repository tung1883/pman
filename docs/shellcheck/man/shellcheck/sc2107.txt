       NAME

       Instead of [ a && b ], use [ a ] && [ b ]. - && can not be used in a [ .. ] test expression. Instead, make two [ .. ] expressions and put the && between them.

       INSTEAD OF A && B , USE A && B

       INSTEAD OF A && B , USE A && B

       PROBLEMATIC CODE

         [ "$1" = "-v" && -z "$2" ]

       CORRECT CODE

         [ "$1" = "-v" ] && [ -z "$2" ]

       RATIONALE

       && can not be used in a [ .. ] test expression. Instead, make two [ .. ] expressions and put the && between them.

       EXCEPTIONS

       None.
