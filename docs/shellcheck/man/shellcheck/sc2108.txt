       NAME

       In [[..]], use && instead of -a. - -a for logical AND is not supported in a [[ .. ]] expression. Use && instead.

       IN .. , USE && INSTEAD OF -A

       IN .. , USE && INSTEAD OF -A

       PROBLEMATIC CODE

         [[ "$1" = "-v" -a -z "$2" ]]

       CORRECT CODE

         [[ "$1" = "-v" && -z "$2" ]]

       RATIONALE

       -a for logical AND is not supported in a [[ .. ]] expression. Use && instead.

       EXCEPTIONS

       None.
