       NAME

       Did you forget the do for this loop? - while read -r line

       DID YOU FORGET THE DO FOR THIS LOOP

       DID YOU FORGET THE DO FOR THIS LOOP

       PROBLEMATIC CODE

         while read -r line
           echo $line
         done

       CORRECT CODE

         while read -r line
         do
           echo $line
         done

       RATIONALE

       ShellCheck found a loop that appears to be missing its do statement. Make sure the loop syntax is correct.

       EXCEPTIONS

       None.
