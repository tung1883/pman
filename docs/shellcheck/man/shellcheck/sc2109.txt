       NAME

       Instead of [ a || b ], use [ a ] || [ b ]. - || cannot be used in a [ .. ] test expression. Instead, make two [ .. ] expressions and put the || between them.

       INSTEAD OF A B , USE A B

       INSTEAD OF A B , USE A B

       PROBLEMATIC CODE

         [ "$1" = "-v" || "$1" = "-help" ]

       CORRECT CODE

         [ "$1" = "-v" ] || [ "$1" = "-help" ]

       RATIONALE

       || cannot be used in a [ .. ] test expression. Instead, make two [ .. ] expressions and put the || between them.

       EXCEPTIONS

       None.
