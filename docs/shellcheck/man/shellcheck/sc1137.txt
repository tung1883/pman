       NAME

       Missing second ( to start arithmetic for ((;;)) loop - for (i=0; i<10; i++))

       MISSING SECOND ( TO START ARITHMETIC FOR (( )) LOOP

       MISSING SECOND ( TO START ARITHMETIC FOR (( )) LOOP

       PROBLEMATIC CODE

         for (i=0; i<10; i++))
         do
           echo $i
         done

       CORRECT CODE

         for ((i=0; i<10; i++))
         do
           echo $i
         done

       RATIONALE

       ShellCheck found an arithmetic for ((;;)) expression where either the (( or the )) did not come as a pair. Make sure to use (( )) and not ( ).

       EXCEPTIONS

       None.
