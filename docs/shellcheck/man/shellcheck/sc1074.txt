       NAME

       Did you forget the ;; after the previous case item? - while getoptions f option

       DID YOU FORGET THE AFTER THE PREVIOUS CASE ITEM

       DID YOU FORGET THE AFTER THE PREVIOUS CASE ITEM

       PROBLEMATIC CODE

         while getoptions f option
         do
           case "${options}"
           in
           f) FTR="${ARG}"
             \?) exit
           esac
         done

       CORRECT CODE

         while getoptions f option
         do
           case "${options}"
           in
           f) FTR="${ARG}";;
             \?) exit;;
           esac
         done

       RATIONALE

       Syntax case needs ;; after the previous case item. If not, syntax error will cause.
