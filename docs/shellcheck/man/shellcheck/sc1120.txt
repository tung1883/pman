       NAME

       No comments allowed after here-doc token. Comment the next line instead. - cat << eof  # --- Start greeting

       NO COMMENTS ALLOWED AFTER HERE-DOC TOKEN. COMMENT THE NEXT LINE INSTEA

       NO COMMENTS ALLOWED AFTER HERE-DOC TOKEN. COMMENT THE NEXT LINE INSTEA

       PROBLEMATIC CODE

         cat << eof  # --- Start greeting --
         Hello
         eof         # --- End greeting ---

       CORRECT CODE

         cat << eof  # --- Start greeting --
         Hello
         eof
                     # --- End greeting ---

       RATIONALE

       The terminator token for a here document must be on an entirely separate line. No comments are allowed on this line.

       Place the comment somewhere else, such as on the following line.

       EXCEPTIONS

       None
