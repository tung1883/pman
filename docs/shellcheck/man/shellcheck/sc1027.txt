       NAME

       Expected another argument for this operator. - ShellCheck found a test operator without an operand. This could be a copy-paste fail, bad linebreak, or trying to use <> instead of != or -n

       EXPECTED ANOTHER ARGUMENT FOR THIS OPERATOR

       EXPECTED ANOTHER ARGUMENT FOR THIS OPERATOR

       PROBLEMATIC CODE

         [ $a -ne ]

       CORRECT CODE

         [ $a -ne $b ]

       RATIONALE

       ShellCheck found a test operator without an operand. This could be a copy-paste fail, bad linebreak, or trying to use <> instead of != or -ne.

       EXCEPTIONS

       None.
