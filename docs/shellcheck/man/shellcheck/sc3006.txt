       NAME

       In POSIX sh, standalone ((..)) is undefined. - variable=1

       IN POSIX SH, STANDALONE ((..)) IS UNDEFINED

       IN POSIX SH, STANDALONE ((..)) IS UNDEFINED

       PROBLEMATIC CODE

         variable=1
         if ((variable)); then
           echo variable is not zero
         fi

       CORRECT CODE

       bash supports standalone ((..)) natively.

       For POSIX compliance, use

         variable=1
         if [ "${variable}" != 0 ]; then
           echo variable is not zero
         fi
