       NAME

       It's not foo &; bar, just foo & bar. - foo &; bar

       IT'S NOT FOO & BAR, JUST FOO & BAR

       PROBLEMATIC CODE

         foo &; bar

       CORRECT CODE

         foo & bar

       RATIONALE

       Both & and ; terminate the command. You should only use one of them.

       EXCEPTIONS

       None.
