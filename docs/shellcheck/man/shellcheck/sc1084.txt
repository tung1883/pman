       NAME

       Use #!, not !#, for the shebang. - echo "Hello World"

       USE # , NOT #, FOR THE SHEBANG

       USE # , NOT #, FOR THE SHEBANG

       PROBLEMATIC CODE

         !#/bin/sh
         echo "Hello World"

       CORRECT CODE

         #!/bin/sh
         echo "Hello World"

       RATIONALE

       The shebang has been accidentally swapped. The # should come first: #!, not !#.

       EXCEPTIONS

       None.
