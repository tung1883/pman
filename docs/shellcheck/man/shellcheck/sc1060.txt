       NAME

       Can't have empty do clauses (use true as a no-op) - for i in 1 2 3; do

       CAN'T HAVE EMPTY DO CLAUSES (USE TRUE AS A NO-OP)

       CAN'T HAVE EMPTY DO CLAUSES (USE TRUE AS A NO-OP)

       PROBLEMATIC CODE

         for i in 1 2 3; do
         done

       CORRECT CODE

         for i in 1 2 3; do
           true
         done

       RATIONALE

       An empty do ... done block is not valid. Use true or : if you need no command at all.

       EXCEPTIONS

       None.
