       NAME

       In [[..]] you shouldn't escape ( or ). - You don't have to -- and can't -- escape ( or ) inside a [[ .. ]] expression like you do in [ .. ]. Just remove the escaping.

       IN .. YOU SHOULDN'T ESCAPE ( OR )

       IN .. YOU SHOULDN'T ESCAPE ( OR )

       PROBLEMATIC CODE

         [[ -e ~/.bashrc && \( -x /bin/dash || -x /bin/ash \) ]]

       CORRECT CODE

         [[ -e ~/.bashrc && ( -x /bin/dash || -x /bin/ash ) ]]

       RATIONALE

       You don't have to -- and can't -- escape ( or ) inside a [[ .. ]] expression like you do in [ .. ]. Just remove the escaping.

       EXCEPTIONS

       None.
