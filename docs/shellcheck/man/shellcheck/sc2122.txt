       NAME

       >= is not a valid operator. Use ! a < b instead. - The operators <= and >= are not supported by Bourne shells. Instead of "less than or equal", rewrite as "not greater than".

       IS NOT A VALID OPERATOR. USE A B INSTEAD

       IS NOT A VALID OPERATOR. USE A B INSTEAD

       PROBLEMATIC CODE

         [[ a >= b ]]

       CORRECT CODE

         [[ ! a < b ]]

       RATIONALE

       The operators <= and >= are not supported by Bourne shells. Instead of "less than or equal", rewrite as "not greater than".

       EXCEPTIONS

       None
