       NAME

       The shell may override time as seen in man time(1). Use command time .. for that one. - time -some some

       THE SHELL MAY OVERRIDE TIME AS SEEN IN MAN TIME(1). USE COMMAND TIME

       THE SHELL MAY OVERRIDE TIME AS SEEN IN MAN TIME(1). USE COMMAND TIME

       PROBLEMATIC CODE

         time -some some

       CORRECT CODE

         command time -some some

       RATIONALE

       time is a built-in command. If you would like to use time from $PATH, you need to use command to execute it as a regular command.

       EXCEPTIONS

       None
