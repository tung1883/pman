       PATHLIB

       Object-oriented filesystem paths.

       PATHLIB.PATH

         Path(*args, **kwargs)

       PurePath subclass that can make system calls.

       Path represents a filesystem path but unlike PurePath, also offers
       methods to do system calls on path objects. Depending on your system,
       instantiating a Path will return either a PosixPath or a WindowsPath
       object. You can also instantiate a PosixPath or WindowsPath directly,
       but cannot instantiate a WindowsPath on a POSIX system or vice versa.

       PATHLIB.PATH.ABSOLUTE

         absolute(self)

       Return an absolute version of this path by prepending the current
       working directory. No normalization or symlink resolution is performed.

       Use resolve() to get the canonical path to a file.

       PATHLIB.PATH.CHMOD

         chmod(self, mode, *, follow_symlinks=True)

       Change the permissions of the path, like os.chmod().

       PATHLIB.PATH.EXISTS

         exists(self, *, follow_symlinks=True)

       Whether this path exists.

       This method normally follows symlinks; to check whether a symlink exists,
       add the argument follow_symlinks=False.

       PATHLIB.PATH.EXPANDUSER

         expanduser(self)

       Return a new path with expanded ~ and ~user constructs
       (as returned by os.path.expanduser)

       PATHLIB.PATH.GLOB

         glob(self, pattern, *, case_sensitive=None)

       Iterate over this subtree and yield all existing files (of any
       kind, including directories) matching the given relative pattern.

       PATHLIB.PATH.GROUP

         group(self)

       Return the group name of the file gid.

       PATHLIB.PATH.HARDLINK_TO

         hardlink_to(self, target)

       Make this path a hard link pointing to the same file as *target*.

       Note the order of arguments (self, target) is the reverse of os.link's.

       PATHLIB.PATH.IS_BLOCK_DEVICE

         is_block_device(self)

       Whether this path is a block device.

       PATHLIB.PATH.IS_CHAR_DEVICE

         is_char_device(self)

       Whether this path is a character device.

       PATHLIB.PATH.IS_DIR

         is_dir(self)

       Whether this path is a directory.

       PATHLIB.PATH.IS_FIFO

         is_fifo(self)

       Whether this path is a FIFO.

       PATHLIB.PATH.IS_FILE

         is_file(self)

       Whether this path is a regular file (also True for symlinks pointing
       to regular files).

       PATHLIB.PATH.IS_JUNCTION

         is_junction(self)

       Whether this path is a junction.

       PATHLIB.PATH.IS_MOUNT

         is_mount(self)

       Check if this path is a mount point

       PATHLIB.PATH.IS_SOCKET

         is_socket(self)

       Whether this path is a socket.

       PATHLIB.PATH.IS_SYMLINK

         is_symlink(self)

       Whether this path is a symbolic link.

       PATHLIB.PATH.ITERDIR

         iterdir(self)

       Yield path objects of the directory contents.

       The children are yielded in arbitrary order, and the
       special entries '.' and '..' are not included.

       PATHLIB.PATH.LCHMOD

         lchmod(self, mode)

       Like chmod(), except if the path points to a symlink, the symlink's
       permissions are changed, rather than its target's.

       PATHLIB.PATH.LSTAT

         lstat(self)

       Like stat(), except if the path points to a symlink, the symlink's
       status information is returned, rather than its target's.

       PATHLIB.PATH.MKDIR

         mkdir(self, mode=511, parents=False, exist_ok=False)

       Create a new directory at this given path.

       PATHLIB.PATH.OPEN

         open(self, mode='r', buffering=-1, encoding=None, errors=None, newline=None)

       Open the file pointed by this path and return a file object, as
       the built-in open() function does.

       PATHLIB.PATH.OWNER

         owner(self)

       Return the login name of the file owner.

       PATHLIB.PATH.READ_BYTES

         read_bytes(self)

       Open the file in bytes mode, read it, and close the file.

       PATHLIB.PATH.READ_TEXT

         read_text(self, encoding=None, errors=None)

       Open the file in text mode, read it, and close the file.

       PATHLIB.PATH.READLINK

         readlink(self)

       Return the path to which the symbolic link points.

       PATHLIB.PATH.RENAME

         rename(self, target)

       Rename this path to the target path.

       The target path may be absolute or relative. Relative paths are
       interpreted relative to the current working directory, *not* the
       directory of the Path object.

       Returns the new Path instance pointing to the target path.

       PATHLIB.PATH.REPLACE

         replace(self, target)

       Rename this path to the target path, overwriting if that path exists.

       The target path may be absolute or relative. Relative paths are
       interpreted relative to the current working directory, *not* the
       directory of the Path object.

       Returns the new Path instance pointing to the target path.

       PATHLIB.PATH.RESOLVE

         resolve(self, strict=False)

       Make the path absolute, resolving all symlinks on the way and also
       normalizing it.

       PATHLIB.PATH.RGLOB

         rglob(self, pattern, *, case_sensitive=None)

       Recursively yield all existing files (of any kind, including
       directories) matching the given relative pattern, anywhere in
       this subtree.

       PATHLIB.PATH.RMDIR

         rmdir(self)

       Remove this directory.  The directory must be empty.

       PATHLIB.PATH.SAMEFILE

         samefile(self, other_path)

       Return whether other_path is the same or not as this file
       (as returned by os.path.samefile()).

       PATHLIB.PATH.STAT

         stat(self, *, follow_symlinks=True)

       Return the result of the stat() system call on this path, like
       os.stat() does.

       PATHLIB.PATH.SYMLINK_TO

         symlink_to(self, target, target_is_directory=False)

       Make this path a symlink pointing to the target path.
       Note the order of arguments (link, target) is the reverse of os.symlink.

       PATHLIB.PATH.TOUCH

         touch(self, mode=438, exist_ok=True)

       Create this file with the given access mode, if it doesn't exist.

       PATHLIB.PATH.UNLINK

         unlink(self, missing_ok=False)

       Remove this file or link.
       If the path is a directory, use rmdir() instead.

       PATHLIB.PATH.WALK

         walk(self, top_down=True, on_error=None, follow_symlinks=False)

       Walk the directory tree from this directory, similar to os.walk().

       PATHLIB.PATH.WRITE_BYTES

         write_bytes(self, data)

       Open the file in bytes mode, write to it, and close the file.

       PATHLIB.PATH.WRITE_TEXT

         write_text(self, data, encoding=None, errors=None, newline=None)

       Open the file in text mode, write to it, and close the file.

       PATHLIB.POSIXPATH

         PosixPath(*args, **kwargs)

       Path subclass for non-Windows systems.

       On a POSIX system, instantiating a Path should return this object.

       PATHLIB.PUREPATH

         PurePath(*args, **kwargs)

       Base class for manipulating paths without I/O.

       PurePath represents a filesystem path and offers operations which
       don't imply any actual filesystem I/O.  Depending on your system,
       instantiating a PurePath will return either a PurePosixPath or a
       PureWindowsPath object.  You can also instantiate either of these classes
       directly, regardless of your system.

       PATHLIB.PUREPATH.AS_POSIX

         as_posix(self)

       Return the string representation of the path with forward (/)
       slashes.

       PATHLIB.PUREPATH.AS_URI

         as_uri(self)

       Return the path as a 'file' URI.

       PATHLIB.PUREPATH.IS_ABSOLUTE

         is_absolute(self)

       True if the path is absolute (has both a root and, if applicable,
       a drive).

       PATHLIB.PUREPATH.IS_RELATIVE_TO

         is_relative_to(self, other, /, *_deprecated)

       Return True if the path is relative to another path or False.

       PATHLIB.PUREPATH.IS_RESERVED

         is_reserved(self)

       Return True if the path contains one of the special names reserved
       by the system, if any.

       PATHLIB.PUREPATH.JOINPATH

         joinpath(self, *pathsegments)

       Combine this path with one or several arguments, and return a
       new path representing either a subpath (if all arguments are relative
       paths) or a totally different path (if one of the arguments is
       anchored).

       PATHLIB.PUREPATH.MATCH

         match(self, path_pattern, *, case_sensitive=None)

       Return True if this path matches the given pattern.

       PATHLIB.PUREPATH.RELATIVE_TO

         relative_to(self, other, /, *_deprecated, walk_up=False)

       Return the relative path to another path identified by the passed
       arguments.  If the operation is not possible (because this is not
       related to the other path), raise ValueError.

       The *walk_up* parameter controls whether `..` may be used to resolve
       the path.

       PATHLIB.PUREPATH.WITH_NAME

         with_name(self, name)

       Return a new path with the file name changed.

       PATHLIB.PUREPATH.WITH_SEGMENTS

         with_segments(self, *pathsegments)

       Construct a new path object from any number of path-like objects.
       Subclasses may override this method to customize how new path objects
       are created from methods like `iterdir()`.

       PATHLIB.PUREPATH.WITH_STEM

         with_stem(self, stem)

       Return a new path with the stem changed.

       PATHLIB.PUREPATH.WITH_SUFFIX

         with_suffix(self, suffix)

       Return a new path with the file suffix changed.  If the path
       has no suffix, add given suffix.  If the given suffix is an empty
       string, remove the suffix from the path.

       PATHLIB.PUREPOSIXPATH

         PurePosixPath(*args, **kwargs)

       PurePath subclass for non-Windows systems.

       On a POSIX system, instantiating a PurePath should return this object.
       However, you can also instantiate it directly on any system.

       PATHLIB.PUREWINDOWSPATH

         PureWindowsPath(*args, **kwargs)

       PurePath subclass for Windows systems.

       On a Windows system, instantiating a PurePath should return this object.
       However, you can also instantiate it directly on any system.

       PATHLIB.WINDOWSPATH

         WindowsPath(*args, **kwargs)

       Path subclass for Windows systems.

       On a Windows system, instantiating a Path should return this object.
