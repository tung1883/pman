       PUSHING METRICS

       Occasionally you will need to monitor components which cannot be scraped. The Prometheus Pushgateway allows you to push time series from short-lived service-level batch jobs to an intermediary job which Prometheus can scrape. Combined with Prometheus's simple text-based exposition format, this makes it easy to instrument even shell scripts without a client library.

        * For more information on using the Pushgateway and use from a Unix shell, see the project's
       README.md.

        * For use from Java see the
       Pushgateway documentation.

        * For use from Go see the Push and Add methods.
        * For use from Python see Exporting to a Pushgateway.
        * For use from Ruby see the Pushgateway documentation.
        * To find out about Pushgateway support of client libraries maintained outside of the Prometheus project, refer to their respective documentation.
